# UI 스타일 (GPT 그림)

상태: 비어 있음 (2026-11-14)

UI 그림은 GPT로 그린다. 사용자가 ChatGPT에서 직접 그려 폴더에 넣고, `ui-designer` 에이전트가 걸러서 붙인다 (사용자 결정, 2026-11-14).
GPT는 같은 요청에도 매번 다르게 그린다. 그래서 세 겹으로 일관성을 지킨다: 뽑을 때(요청문 틀과 기준 세트), 고를 때(스크립트 검사와 기준 세트 대조), 다음번(요청 기록으로 틀을 고침).
스타일 문장, 기준 세트, 요청문 틀은 사용자가 정한다. 상태가 `정함`이 되기 전에는 ui-designer 에이전트가 "스타일" 할 일만 한다.

## 틀과 버튼

<그림 / Godot 테마. 사용자가 고른다. 제안: 테마 (늘어나는 틀은 그림이면 깨지기 쉽고, 테마면 검수할 그림이 준다. 그림은 아이콘과 장식에 쓴다)>

## 기준 세트

사용자가 확정한 부품 종류마다의 기준 그림이다. 모든 요청에 같은 종류의 기준 그림을 함께 넣고, 모든 후보를 이것과 견준다.

| 부품 종류 | 기준 그림 | 그림 크기 | 차지하는 면적 | 외곽선 | 빛 방향 | 게임에 보이는 크기 |
|---|---|---|---|---|---|---|
| <예: 아이콘> | <`art_src/ui/style/<파일>.png`> | <px> | <투명 여백 px> | <굵기> | <예: 왼쪽 위> | <px> |

## 요청문 틀 (판 0)

모든 요청문은 이 틀에서 시작한다. 틀은 짧게 유지한다. 길면 GPT가 뒤쪽을 무시한다.
바꾸면 판 번호를 올리고 아래 "틀을 고친 내력"에 한 줄 적는다.

- 고정 스타일 문장: <모든 요청의 첫머리. 색, 재질, 선 굵기, 장식의 양, 빛 방향>
- 부품 종류마다의 덧붙임:
  - 아이콘: <규격 문장>
  - 버튼: <규격 문장. 상태 네 개를 같은 크기로 나란히>
  - 칸: <규격 문장>
- 바뀌는 자리: <물건 이름>, <형태 설명>
- 늘 붙이는 말: 투명 배경 PNG, 글자 없음

## 지킬 것

- 글자는 그림에 넣지 않는다. 모든 글자는 게임 글꼴로 넣는다.
- 투명 배경 PNG로 받는다. 받은 후보는 고르지 말고 전부 inbox에 넣는다.
- 버린 후보는 지우지 않는다 (`art_src/ui/<화면 id>/` 아래 rejected 폴더). 살릴 수 있다.

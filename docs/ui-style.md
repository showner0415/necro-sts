# UI 스타일 (GPT 그림)

상태: 비어 있음 (2026-11-14)

UI 그림은 GPT로 그린다. 사용자가 ChatGPT에서 직접 그려 폴더에 넣고, `ui-designer` 에이전트가 다듬어 붙인다 (사용자 결정, 2026-11-14).
GPT는 요청마다 그림이 조금씩 달라지므로, 모든 요청은 이 문서의 "스타일 문장"과 "기준 그림"에서 시작한다.
스타일이 정해지면 상태를 `정함`으로 바꾼다. 그 전에는 ui-designer 에이전트가 "스타일" 할 일만 한다.

## 스타일 문장

<사용자가 고른 안. 모든 GPT 요청문의 첫머리에 그대로 넣는 문장. 색, 재질, 선 굵기, 장식의 양, 빛 방향>

## 기준 그림

<사용자가 고른 그림의 경로 (`art_src/ui/style/` 아래). 모든 요청에 함께 넣는다>

## 지킬 것

- 글자는 그림에 넣지 않는다. 모든 글자는 게임 글꼴로 넣는다.
- 투명 배경 PNG로 받는다.
- 늘어나는 것(창 틀, 칸, 버튼 바탕)은 9-slice로 쓴다. 모서리 장식은 모서리에만 둔다.
- <고른 안에서 나온 규칙>

## 시안

<ui-designer 에이전트의 "스타일" 할 일이 세 안과 요청문을 적는다>

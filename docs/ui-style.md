# UI 스타일 (GPT 그림)

상태: 비어 있음 (2026-11-14)

UI 그림은 GPT로 그린다. `ui-designer` 에이전트가 Codex CLI로 후보를 뽑고(ChatGPT 구독 한도, `tools/ui_gen/codex_image.sh`), 걸러서 붙인다 (사용자 결정, 2026-11-15). Codex가 없으면 사용자가 ChatGPT에서 직접 그려 넣는다.
GPT는 같은 요청에도 매번 다르게 그린다. 그래서 세 겹으로 일관성을 지킨다: 뽑을 때(요청문 틀과 기준 세트), 고를 때(스크립트 검사와 기준 세트 대조), 다음번(요청 기록으로 틀을 고침).
스타일 문장, 기준 세트, 요청문 틀은 사용자가 정한다. 상태가 `정함`이 되기 전에는 ui-designer 에이전트가 "스타일" 할 일만 한다.

## 틀과 버튼

창 틀만 그림(9-slice)으로 하고, 칸·버튼은 Godot 테마로 한다 (사용자 결정, 2026-11-15). 모든 창이 틀 그림 하나를 같이 쓴다. 각진 돌 느낌은 틀 그림으로 살리고, 검수할 그림은 틀 하나로 줄인다.

## 기준 세트

사용자가 확정한 부품 종류마다의 기준 그림이다. 모든 요청에 같은 종류의 기준 그림을 함께 넣고, 모든 후보를 이것과 견준다.

| 부품 종류 | 기준 그림 | 그림 크기 | 차지하는 면적 | 외곽선 | 빛 방향 | 게임에 보이는 크기 |
|---|---|---|---|---|---|---|
| <예: 아이콘> | <`art_src/ui/style/<파일>.png`> | <px> | <투명 여백 px> | <굵기> | <예: 왼쪽 위> | <px> |

## 요청문 틀 (판 0)

모든 요청문은 이 틀에서 시작한다. 틀은 짧게 유지한다. 길면 GPT가 뒤쪽을 무시한다.
바꾸면 판 번호를 올리고 아래 "틀을 고친 내력"에 한 줄 적는다.

- 고정 스타일 문장: <모든 요청의 첫머리. 색, 재질, 선 굵기, 장식의 양, 빛 방향>
- 부품 종류마다의 덧붙임:
  - 아이콘: <규격 문장>
  - 버튼: <규격 문장. 상태 네 개를 같은 크기로 나란히>
  - 칸: <규격 문장>
- 바뀌는 자리: <물건 이름>, <형태 설명>
- 늘 붙이는 말: 투명 배경 PNG, 글자 없음

## 지킬 것

- 글자는 그림에 넣지 않는다. 모든 글자는 게임 글꼴로 넣는다.
- UI 그림은 픽셀 아트가 아니어도 된다. 대신 팔레트 색감과 어두운 분위기는 게임 화면에 맞춘다. UI 장식에 네크로맨서·해골(뼈·머리뼈) 모티프는 넣지 않는다. 아이템 아이콘은 예외다 (사용자 결정, 2026-11-15, `docs/art-direction.md`의 "스타일").
- 투명 배경 PNG로 받는다. 직접 받을 때는 고르지 말고 받은 것을 전부 inbox에 넣는다.
- 요청문은 영어로 쓴다.
- 버린 후보는 지우지 않는다 (`art_src/ui/<화면 id>/` 아래 rejected 폴더). 살릴 수 있다.

## 시안

2026-11-15, 사용자 설명: "ui시안 뽑아줘. 로우폴리 스타일라이즈드 게임에서 쓸 거 같은 느낌으로. 글자는 잘 읽혔으면 좋겠어."
모두 **제안**이다. 사용자가 고르기 전에 적었다 (아래 "고른 시안"에서 고름). Codex CLI로 안마다 2장씩 받았다 (2026-11-15, 모두 6장. 그림 `art_src/ui/inbox/style/`, 번호 붙은 비교판 `art_src/ui/inbox/style/compare/style_sheet.png`, 받는 법·요청문 `art_src/ui/inbox/style/prompts.md`). inbox는 git에 올리지 않으므로(.gitignore) 그림과 요청문은 받은 컴퓨터에만 있다.
시안 화면은 모두 같다: 인벤토리 창 (제목 줄, 칸 5×3, 닫기 버튼, 아이콘 뼈·머리뼈·물약·열쇠, 아래 안내 띠). 글자 자리는 빈 판으로 둔다. 칸 5×3은 시안용이고 실제 게임 인벤토리 칸 수와는 무관하다 (사용자, 2026-11-15).
색·분위기는 셋 모두 같은 문장으로 요청했다: 어둡고 뼈·네크로맨서 느낌, Endesga 32의 어두운 색 쪽과 뼈색에 가깝게 (181425, 262b44, 3a4466, 3e2731, 733e39, 뼈 ead4aa, e4a672). 팔레트 색으로 정확히 맞출지는 미정이라 "가깝게"로만 썼다.

- 받은 시안 (비교판 번호, 에이전트가 본 것. 판정 아님):
  - 1·2 (A): 각진 돌 틀에 청록 선, 모서리 뼈·머리뼈. 1은 갈색 돌, 2는 슬레이트 보라 돌에 주황 닫기 X. 제목 판·아래 띠 비어 있음.
  - 3·4 (B): 모깎은 숯보라 판과 자주갈색 칸, 초록 선택 칸 하나. 머리뼈 문양이 제목 판 안 왼쪽에 들어가 제목 글자는 그 오른쪽부터 써야 한다.
  - 5·6 (C): 뼈 막대 틀에 보라 수정, 위 가운데 머리뼈, 굵은 검은 외곽선. 판은 반투명이 아니라 거의 검은 불투명으로 나왔다. 닫기 버튼이 틀 모서리에 걸친다.
  - 여섯 장 모두 칸 5×3, 글자·숫자·룬 없음, 그림 전체에 배경이 있는 1672×941 RGB (투명 없음).
- 틀·버튼 (제안): Godot 테마로 한다. 늘어나는 틀은 그림이면 9-slice가 깨지기 쉽고, 테마면 화면마다 검수할 그림이 준다. 그림은 아이콘과 모서리 장식에만 쓴다. A·B는 테마로 거의 옮길 수 있고, C는 모서리 장식 그림이 많이 든다. → 사용자는 틀만 그림, 칸·버튼은 테마로 골랐다 (위 "틀과 버튼").
- 요청문 (영어, 그대로 붙여 넣는다): `art_src/ui/inbox/style/prompts/style_a.txt`, `style_b.txt`, `style_c.txt`. 공통으로 둘째 줄의 색·분위기 문장과 "글자 자리는 평평하고 어둡고 고른 빈 판, 장식은 글자 자리와 칸을 침범하지 않음, 글자·숫자·룬·색 견본 없음"을 넣었다.

### 다시 뽑은 시안: A2 장식 뺌 (2026-11-15)

사용자 판정 (위 비교판을 보고): "1번이 제일 좋긴한데, ui가 전체적으로 네크로맨서랑 해골에 너무 무리하게 많이 치우쳐졌어. 그런 요소는 굳이 넣을 필요 없으니까 지워줘." (요청 기록에 적음)
그래서 A안만 다시 뽑았다. 모두 **제안**이다. 사용자가 고르기 전에 적었다 (아래 "고른 시안"에서 고름). Codex CLI로 3장 받았다 (함께 넣은 그림 style_a_1.png, 요청문 `art_src/ui/inbox/style/prompts/style_a2.txt`, 바꾼 것은 `art_src/ui/inbox/style/prompts.md`의 "다시 뽑음: A2").
- 요청문에서 바꾼 것: 네크로맨서·뼈·머리뼈 분위기 말과 모서리 장식을 빼고 어두운 동굴 분위기만 둠, 배경에 뼈 소품 금지, 돌 색을 갈색(#733e39 → #3e2731)으로 못 박고 보라·슬레이트 금지, 9-slice로 늘리기 좋게 모서리 사이를 고른 반복 무늬로, 참고 그림의 머리뼈·뼈 장식은 따라 그리지 말 것. 칸 안 아이템 아이콘(뼈·머리뼈·물약·열쇠)은 게임 아이템이라 그대로 둠.
- 비교판 `art_src/ui/inbox/style/compare/style_a2_sheet.png` (1 = 기존 1번 style_a_1, 2·3·4 = style_a2_1·2·3). 에이전트가 본 것 (판정 아님):
  - 2·3·4 모두: 틀·모서리에 머리뼈·뼈 없음, 배경에 뼈·갈비뼈 없음, 돌은 갈색(틀 왼쪽 평균 743a34·703f39·703f41, 기존 1은 5c3942로 더 어둡고 자줏빛), 제목 판·아래 띠는 비고 거의 검정(평균 17131d 안팎), 칸 5×3, 글자·숫자·룬 없음. 배치와 아이콘 자리는 기존 1을 거의 그대로 따랐다. 세 장 모두 기존 1보다 돌이 밝고 붉다.
  - 2 (style_a2_1): 바깥 윤곽이 곧고 모서리만 비스듬히 깎였으며, 위·아래 가장자리가 고른 삼각 면 반복이다. 셋 중 9-slice로 늘리기 가장 좋아 보인다. 돌이 가장 붉은 주황 갈색이다.
  - 3 (style_a2_2): 윤곽이 울퉁불퉁하고 위 가장자리에 혹이 있다. 네 모서리가 머리뼈가 있던 자리처럼 불룩하다. 배경은 갈색.
  - 4 (style_a2_3): 3과 비슷한 울퉁불퉁한 윤곽. 돌이 셋 중 기존 1의 색에 가장 가깝고(약간 자줏빛 갈색), 배경도 기존 1처럼 자줏빛이 돈다.
  - 시안은 배경 위에 창 전체를 그린 한 장(1672×941, 투명 없음)이라 그대로 9-slice 그림으로 쓸 수는 없다. 틀 그림은 고른 안으로 기준 세트를 만들 때 따로 투명 배경으로 요청한다 (제안).
- **고른 시안** (사용자 결정, 2026-11-15): A2 비교판 3번(`style_a2_2.png`)으로 간다. 그림과 요청문은 git에 올려 두 컴퓨터에서 쓴다: `art_src/ui/style/style_a2_2.png`, `art_src/ui/style/style_a2.txt` (사용자 결정, 2026-11-15). 틀 돌 색의 밝기는 기존 1(더 어둡고 자줏빛)과 새 시안(밝고 붉음)의 그 사이로 한다. 기준 세트는 이 시안으로 만든다. 스타일 상태는 기준 세트를 확정한 뒤 `정함`으로 바꾼다.

# 아트 방향과 에셋 규칙

아직 대부분 미정이다. 첫 에셋을 만들 때 `make-asset` 스킬이 아래 미정 항목을 사용자에게 묻고, 답을 이 문서에 적는다. 한 번 정한 항목은 이후 모든 에셋에 적용한다.

## 기본 방향 — 미정

| 항목 | 값 | 상태 |
|---|---|---|
| 시점 | 2D 탑다운 / 3D 탑다운 / 2.5D | 미정 |
| 스타일 | 픽셀 아트 / 로우폴리 / 단순 도형 등 | 미정 |
| 기준 크기 | 2D: 타일·캐릭터 픽셀 크기 (예: 16px, 32px) / 3D: 캐릭터 기준 높이 | 미정 |
| 팔레트 | 색 개수와 주요 색 | 미정 |
| 카메라 각도 | 수직 위 / 비스듬한 위 | 미정 |

## 제작 도구

시점이 정해지면 그에 맞는 도구를 쓴다.

- **2D**: 생성 스크립트로 PNG를 만든다.
  - Python + Pillow가 설치되어 있으면 `tools/asset_gen/*.py`
  - 없으면 Godot 스크립트(`Image` 클래스, `save_png`)로 `tools/asset_gen/*.gd`를 만들고 `bash tools/godot.sh --headless -s <스크립트>`로 실행
- **3D**: Blender MCP로 모델을 만들고, 원본 `.blend`는 `art_src/`에, 내보낸 `.glb`는 `assets/`에 둔다. Blender MCP가 연결되어 있지 않으면 사용자에게 Blender를 켜고 애드온에서 연결해 달라고 요청한다.
- 어느 쪽이든 결과물을 다시 만들 수 있어야 한다. 조정은 파라미터를 바꿔 재생성하는 방식으로 한다.

## 제안 (사용자 확인 전)

- **언데드 에셋 재사용**: 몬스터마다 언데드 버전이 있으므로, 언데드는 원본 몬스터 에셋에 공통 변형(채도 낮추기, 뼈색 톤, 빛나는 눈 등)을 적용해 만드는 방식을 제안한다. 생성 스크립트에 "언데드 변형" 옵션을 두면 몬스터 하나를 추가할 때 언데드도 같이 나온다.
- **네임드 표시**: 네임드 언데드는 같은 에셋에 테두리나 색 강조를 더하는 방식을 제안한다.

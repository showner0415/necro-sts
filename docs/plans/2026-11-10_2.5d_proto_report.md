# 2.5D 시제품 1차 결과 (2026-11-10, `proto-2.5d` 브랜치)

직접 해 보기: `bash tools/godot.sh --path . res://proto_25d/proto_cave.tscn`
키: F3 직교/원근, F4 팔레트 후처리, F5 앞벽 (끔 / 반투명 / 잘라내기), F6 3D/2D 화면, F2 시야.

## 스크립트로 잰 결과

명령: `bash tools/godot.sh --path . -s tests/proto/check_view_3d.gd` (창이 뜬다)

| 기준 | 결과 |
|---|---|
| 네크로맨서 그림이 원본과 픽셀까지 같음 (직교) | 통과: 불투명 290개 중 290개 |
| 쥐 그림 가운데를 8방향에서 조준해 맞힘 (화면 → 탄 높이 평면) | 통과: 8 / 8 |
| 시야 판정과 화면 밝기 일치 (기준 95%) | 통과: 98.5% (자리·방향 5개) |
| 걸을 때 바닥이 정수 픽셀로만 옮겨 감 | 통과: 가장 낮은 일치 100% |
| 프레임 시간 중앙값 | 2D 0.60ms, 3D 1.10ms, 3D + 그림자 빛 8개 1.60ms |

쥐 하나와 작은 굴 하나의 값이다. 2배 맵(480×232칸)과 실제 언데드 시야는 아직 재지 않았다. 프레임 시간은 이 컴퓨터의 값이다.

`bash tests/run_all.sh`: 조준 경로를 고친 뒤에도 통과 (2D 게임은 그대로).

## 계획에서 달라진 것

- 부채꼴: 스포트 빛으로 만들었더니 원뿔 가장자리와 둘레 빛이 2D 규칙보다 일찍 어두워져 일치율이 91.6%였다. 계획서의 대안대로 **전방향 빛 하나가 벽 그림자만 맡고, 부채꼴·둘레 원은 지형 셰이더가 2D 규칙과 같은 모양으로 계산**하게 바꿨다 (98.5%).
  - 언데드 시야를 넣을 때는 셰이더가 빛마다 다른 모양을 알아야 한다. 전체 이전의 시야 단계에서 정한다.
- 앞벽: 잘라낸 자리에 낮은 윗면을 깔았다 (없으면 구멍처럼 보인다).

## 눈으로 볼 것 (`docs/plans/2.5d_shots/`)

- `rat.png` 직교, `rat_persp.png` 원근, `rat_palette.png` 팔레트 후처리
- `rat_south.png` 앞벽 끔, `rat_south_cut1.png` 반투명, `rat_south_cut2.png` 잘라내기
- 원근은 벽이 기울고 그림 크기가 깊이마다 달라진다.
- 팔레트 후처리는 빛 없는 지형(어두운 색)이 모두 같은 색으로 뭉친다. 지형이 거의 사라진다.

## 아직 안 한 것

- 조작감과 벽 가림의 답답함은 직접 해 봐야 안다.
- 맞았을 때 번쩍임, 스태미나 도넛, 돌진 선 같은 바닥 표시는 시제품에 없다.

## 팔레트: 어두운 지형에서 벽과 바닥 구분 (`2.5d_shots/dark_palette_compare.png`, 위 끔·아래 켬)

빛 밖 영역(화면 x 120~249, y 60~289)의 색을 셌다.

| 표면 | 팔레트 끔 | 팔레트 켬 |
|---|---|---|
| 바닥 (체크 두 색) | 12090c / 070a15 | 둘 다 181425 |
| 벽 윗면 | 1f2532 | 262b44 |
| 벽 앞면 | 343b46 | 262b44 |

- 벽과 바닥은 구분된다 (181425 대 262b44).
- 바닥의 체크 무늬와, 벽 윗면·앞면의 구분은 사라진다. 어두운 곳의 벽은 입체감 없는 납작한 판으로 보인다.
- 어두운 바닥이 181425가 된다. 이 색은 "외곽선 전용, 게임 화면 바닥에 쓰지 않는다"는 확정 규칙의 색이다. 빛 밖에서도 보이는 언데드의 외곽선이 바닥에 묻힐 수 있다.
- 지금 임시 색 기준의 결과다. 타일 그림이 들어오면 다시 봐야 한다.
- 팔레트 끔 상태의 어두운 바닥은 2D 시야(원래 색의 0.4배)보다 조금 더 어둡다 (3e2731 바닥이 2D 약 191014, 3D 12090c). 밝기를 선형 색으로 곱했기 때문이다.

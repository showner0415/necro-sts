# 시험 지역을 무리 연습장으로 (2026-11-16)

상태: 진행 중 (2단계) (2026-11-16)
브랜치: `main` (따로 따지 않음)

## 목표

시험 지역을 넓혀 몬스터 무리를 두고 연습 장소로 쓴다 (사용자 요청, 2026-11-16: "시험장소 좀 더 넓혀서 여기도 몬스터 무리 적용시켜서 연습장소로 쓸 수 있게 해줘.").
하지 않는 것: 몬스터·무리의 수치 바꾸기, 얕은 굴 바꾸기, 밸런스 기준값 다시 재기 (테스트 싸움터가 그대로라 필요 없다).

## 정한 것 (사용자, 2026-11-16)

- 시험 지역을 통째로 연습장으로 바꾼다. 지형은 평지 + 둘레 벽, 크기는 얕은 굴의 1/4쯤(약 4000×3000px).
- 무리: 쥐 무리(패거리·큰 무리), 멧돼지·섞인 무리, 투석병·박쥐 무리, 동굴 두꺼비.
- 구역: 남쪽 끝에서 시작하고, 북쪽으로 갈수록 어렵다.
- 동굴 두꺼비는 2마리 무리다. 놓으면서 "맵에 놓을 때 구현한다"고 정해 둔 항목(줄은 벽까지만, 막히면 옮겨 서기)과 언데드 두꺼비 예고 0도 구현한다. 막혔다고 보는 기준·옮기는 거리는 그 단계 전에 묻는다.
- 지금 시험 지역 씬은 테스트 전용 싸움터로 남기고, 테스트·측정·도구는 그쪽을 쓴다.
- 1단계 뒤 (선택 UI, 2026-11-16):
  - 구역 순서는 남쪽부터 ① 쥐(패거리·큰 무리) ② 투석병·박쥐 무리 ③ 멧돼지·섞인 무리 ④ 두꺼비 (측정한 난이도 순서).
  - 아래 "제안 값"을 그대로 쓴다: 125×94칸, 구역 사이는 감지 거리보다 넓게, 탈출 지점 둘(시작 자리 곁·맨 북쪽), 상자 둘(멧돼지 근처·시작 자리 곁), 배치 PNG 스크립트 + `map_from_png.gd`, 윤곽 없이 칸 충돌.
  - 무리 종류마다 무리 자리 둘.
  - 지역 이름은 "연습장" (`data/regions/test_region.tres`의 `display_name`. 파일 이름은 그대로).

## 문제와 위험

| # | 문제 | 내용 | 대응 |
|---|---|---|---|
| 1 | 시험 지역에 기대는 파일이 많다 | 테스트·측정·도구 44개 파일, 그중 28곳이 씬 안 노드 이름(`Rat1`, `BatPack` 등)과 자리에 기댄다. 밸런스 측정 싸움터도 이 씬이다 | 1단계에서 지금 씬을 테스트 싸움터로 복사하고 경로만 바꾼다. 내용이 같아 기대값·측정 기준이 그대로다 |
| 2 | 두꺼비를 맵에 놓으면 할 일이 따라온다 | 줄은 벽까지만 긋기와 앞벽 반투명 세 줄, 막히면 옮겨 서기(기준 미정), 언데드 예고 0 | 3단계로 따로 둔다. 시작 전에 미정을 묻는다 |
| 3 | 두꺼비 무리 색이 맵 PNG 규칙에 없다 | 무리 종류는 색 하나씩이다 (`docs/maps/map_png_rules.md`) | 3단계에서 팔레트 색 하나를 **제안**으로 정하고 묻는다 |

## 제안 값 (2026-11-16 사용자가 "이대로" 고름, 위 "정한 것")

| 값 | 제안 | 이유 |
|---|---|---|
| 맵 크기 | 125×94칸 (4000×3008px) | "약 4000×3000"에 맞는 칸 수 |
| 구역 | 남쪽부터 띠 넷. 순서는 "정한 것"의 ①~④ (처음 제안은 ② 멧돼지·섞인 ③ 투석병·박쥐였다). 띠 사이는 감지 거리보다 넓게 비운다 | 한 구역만 골라 연습하기 쉽게 |
| 윤곽 | 만들지 않고 칸 충돌 (`map_from_png.gd:134-140`) | 곧은 둘레 벽뿐이라 필요 없다. 컴퓨터마다 굽지 않아도 된다 |
| 탈출 지점 | 시작 자리 곁 하나, 맨 북쪽 하나 | 연습하다 바로 돌아가기 쉽게 |
| 상자 | 멧돼지 근처 하나, 몬스터 없는 곳(시작 자리 곁) 하나 | 지금 확정 줄("시험 지역에는 임시로 두 곳")과 같게 |
| 만드는 방식 | 배치 PNG를 스크립트(`tools/map_png/make_practice_layout.gd`, 새)로 그리고 `tools/map_from_png.gd`로 씬을 만든다 | 다시 만들 수 있게. 고칠 때 PNG만 고친다 |

# 게임 설계

이 문서는 사용자가 정한 내용(**확정**)과 아직 정하지 않은 내용(**미정**)을 나눠 적는다. 미정 항목은 구현하기 전에 사용자에게 묻는다.

## 한 줄 요약

약한 네크로맨서가 약한 몬스터의 뼈로 언데드를 소환하고, 그 언데드로 더 강한 몬스터를 잡아 그 몬스터의 머리뼈를 얻으며 점점 강한 군단을 만드는 탑다운 게임.

## 핵심 루프 (확정 내용으로 구성)

1. 네크로맨서가 약한 기본 공격으로 하위 몬스터를 잡는다.
2. 몬스터가 뼈를 떨어뜨린다. 일정 확률로 머리뼈도 떨어뜨린다.
3. 머리뼈와 뼈(또는 뼈를 조합한 재료)로 그 몬스터의 언데드를 소환한다.
4. 언데드로 더 강한 몬스터를 잡고, 그 몬스터의 머리뼈를 얻는다.
5. 지역별 퀘스트를 수행한다.

## 시점 — 확정

- 2.5D: 캐릭터는 2D 도트 그림, 맵은 3D. 게임 규칙은 2D 평면 그대로이고 화면만 3D로 그린다 (`docs/art-direction.md`, 2026-11-10 2D 탑다운에서 바꿈)

## 네크로맨서 — 확정

- 공격 수단은 기본 공격 하나뿐이다.
- 기본 공격은 매우 약하다. 네크로맨서 혼자서는 강한 몬스터를 잡는 것이 거의 불가능하다.
- 하위 몬스터는 기본 공격으로 잡을 수 있다.
- 기본 공격은 마우스로 조준해서 쏘는 원거리 공격이다.
- 탄은 네크로맨서의 몸 가운데에서 나간다 (2026-11-08. 그림의 지팡이 보석에서 나가게 했다가, 걷기 애니메이션에서 지팡이가 프레임마다 움직여 되돌림).
- 몸은 늘 조준 방향(마우스 쪽)을 본다. 멈춰 있으면 정지 그림, 움직이면 걷기 애니메이션이고, 바라보는 방향과 90도 넘게 다른 쪽으로 움직이면 걷기를 거꾸로 재생한다 (2026-11-08).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요): 걷기 재생 속도는 이동 속도 / 걷는 속도(80)에 비례한다 (쏘며 걷기 0.6배, 뛰기 1.6배, 구르기는 최대 2배, 최소 0.5배). 구르기 그림이 없어 구르는 동안도 걷기를 빠르게 재생한다. 밀려나는 동안은 정지 그림이다. 기본 재생 속도는 초당 12프레임(임시값, `tools/asset_gen/necromancer_anim.gd`의 `WALK_FPS`).
- 쏘는 동안(공격 버튼을 누르고 있는 동안)은 이동 속도가 줄어든다 (걷기 80 → 50, 임시값). 거리를 두고 쏘기만 해서는 모든 몬스터를 피해 없이 잡을 수 있었기 때문이다 (밸런스 측정).
  - 쏘는 동안은 뛸 수 없다. 벗어나려면 쏘기를 멈추고 뛴다.
- 기본 공격 탄 속도는 800, 사거리는 300이다 (사용자 결정, 2026-11-12. 200·160에서 400·300으로, 다시 속도만 800으로 올림. 값은 `data/attacks/basic_attack.tres`).
- 기본 공격에는 선딜레이가 없다. 공격 버튼을 누르면 그 순간의 마우스 쪽으로 바로 쏜다 (사용자 결정, 2026-11-13. 2026-11-12에 선딜레이 0.3초를 넣었다가 지움. 선딜레이 코드도 지웠다):
  - 후딜레이는 0.8초다 (공격 데이터의 `cooldown`). 누르고 있으면 후딜레이가 끝나자마자 다음 탄을 쏜다. 그래서 0.8초마다 쏜다 (사용자 결정, 2026-11-13. 선딜레이가 있을 때는 1.1초마다였다).
  - 후딜레이 중에 공격 버튼을 누르면 무시한다. 예약하지 않는다 (사용자 결정, 2026-11-12).
- 탄의 보이는 크기와 맞는 범위는 공격 데이터에서 따로 조절한다. 지금은 둘 다 반지름 6 (지름 12px, 사용자 결정 2026-11-12. 전에는 반지름 3: 2에서 키움, 쥐·박쥐 옆에 놓은 후보 2 / 3 / 5 중에서 고름).

## 시야 — 확정 (2026-11-08)

- 플레이어 화면에는 네크로맨서에서 마우스 방향으로 뻗은 부채꼴 안만 보인다. 마우스 방향을 가운데로 좌우 35도씩, 합쳐서 70도다.
- 이 규칙은 플레이어가 보는 화면에만 적용한다. 몬스터가 네크로맨서·언데드를 감지하는 규칙은 바꾸지 않는다.
- 부채꼴 밖에서는 몬스터, 물건, 몬스터가 쏜 탄이 보이지 않는다. 벽과 바닥은 어둡게 보인다.
- 부채꼴 안에서도 벽과 바위 뒤는 보이지 않는다.
- 보이는 거리는 화면 끝까지다. 나중에 줄일 수 있게 값으로 둔다.
  - **제안**: 거리 값은 처음에 화면 끝(가로 반 화면 = 10칸 이상)을 덮는 값으로 둔다.
- 네크로맨서 둘레의 작은 원 안은 방향과 상관없이 항상 보인다.
  - **제안**: 반지름 1.5칸 (48px).
- 부채꼴 가장자리는 칼같이 끊지 않고 서서히 어두워진다. 마우스 방향에서 좌우 23도까지는 완전히 밝고, 23~35도는 매끄럽게 어두워진다 (2026-11-08 바꿈. 처음에는 16px 칸마다 계산해 몇 단계로 끊었는데, 칸 단위로 일렁거려서 Godot 2D 조명으로 다시 만들었다).
- 조명 방식 (2026-11-08):
  - 지형(벽·바닥)만 어둡게 한다. 몸(네크로맨서·언데드·몬스터)은 늘 원래 밝기다.
  - 네크로맨서에 단 빛이 마우스 방향으로 돌며 지형을 밝힌다. 벽에는 그림자가 진다 (2026-11-10 3D로 옮김. 2D의 빛 그림과 벽 7px 띠는 3D의 빛과 벽면으로 바뀌었다).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요): 빛은 벽보다 낮은 높이 12px에 있고, 벽 앞면은 빛을 받고 윗면은 어둡다. 플레이어 빛과 언데드 빛이 겹친 곳은 원래 색의 약 1.17배다 (2D는 약 1.35배). 언데드 빛은 네크로맨서에게 가까운 8마리까지다.
  - 부채꼴 밖의 몬스터·물건·탄은 부채꼴 + 벽 가림 규칙으로 판정해서 서서히 나타나고 사라진다.
- 개발용으로 시야를 켜고 끄는 키가 있다 (F2). 배포판에서는 동작하지 않는다.
- 한 번 본 곳의 지형(벽과 바닥)은 어둡게 남는다. 몬스터와 물건은 다시 볼 때만 보인다.
- 동굴 같은 위험 지역에만 적용한다. 거점은 전부 보인다. 지역 데이터에서 켜고 끌 수 있다.
- 내 언데드는 부채꼴 밖에서도 항상 보인다 (언데드 둘레의 몬스터는 규칙대로 안 보인다).
- 한 번도 본 적 없는 지형도 처음부터 어둡게 보인다. 그래서 "본 지형은 어둡게 남는다"는 따로 기억하지 않아도 늘 맞는다 (지형은 보이는 곳이 밝고 나머지는 어둡다).
- 부채꼴 밖에서 오는 공격의 예고(박쥐 무리 동시 돌진, 멧돼지 돌진)도 보이지 않는다. 예고 중이어도 따로 드러내지 않는다.
- 밸런스 측정 봇은 기본으로 시야와 상관없이 모든 몬스터 위치를 안다 (`--sight=full`, 사용자 결정 2026-11-09). 시야 규칙을 따르게 재려면 `--sight=cone`: 보이는 몬스터에만 반응하고, 안 보이던 몬스터는 보이는 순간부터 반응 시간을 센다.
- 언데드 시야 (2026-11-08):
  - 언데드도 플레이어와 같은 방식의 시야(부채꼴, 벽 뒤 가림)를 가진다. 몸 둘레 원은 없다.
  - 방향은 언데드가 움직이는 쪽, 싸울 때는 공격하는 쪽이다.
  - 보는 거리는 플레이어의 40~50%다.
  - 지형도 밝히되 플레이어 빛보다 조금 어둡다. 플레이어 빛과 겹치는 곳은 더 밝아져도 그대로 둔다.
  - 몬스터·물건은 플레이어 시야나 언데드 시야 중 하나에라도 들어오면 보인다.
  - 시야 값(거리·각도 등)은 따로 둔 시야 데이터(`SightData`)에 두고, 몬스터 데이터가 가리킨다. 몬스터마다 다르게 할 수 있다 (나중에 정찰용 까마귀 등).
  - 측정 봇은 언데드 시야로 보이는 몬스터도 안다.
  - 값 (사용자 확정): 보는 거리 200px (플레이어 448의 약 45%). 전체 각도 70도, 완전히 밝은 각도 46도 (플레이어와 같은 비율). 지형 밝기는 플레이어 빛의 약 75%.
  - **제안** (구현에는 이렇게 넣었다, 확인 필요): 방향은 초당 360도까지만 돈다. 싸울 때(대상이 있을 때)는 대상 쪽, 움직일 때는 움직이는 쪽, 멈추면 마지막 방향. 시야 데이터가 비어 있는 몬스터는 기본값(`data/sight/undead_default.tres`)을 쓴다.
  - 메모 (2026-11-08 측정, 2배 맵 멧돼지 굴, 프레임 시간 중앙값): 시야가 늘리는 시간은 언데드 0 / 2 / 4 / 8마리에서 +0.48 / +0.65 / +0.79 / +1.05ms. 플레이어 빛과 언데드 빛이 겹친 곳은 원래 색의 약 1.35배로 밝다 (언데드 빛만 받은 곳은 0.75배).
- 측정 봇이 마우스를 돌리는 방식 (2026-11-08):
  - 보이는 몬스터가 있으면 공격 대상을 본다.
  - 보이는 몬스터가 없으면 걷는 방향을 본다. 2초마다 좌우 60도를 한 번씩 0.4초 동안 둘러본다. 숙련 봇은 1.2초마다, 초보 봇은 3초마다다.
  - 안 보이는 쪽에서 맞으면 0.3초 뒤 맞은 방향으로 돌아본다.
  - 살아 있는 몬스터를 놓치면 마지막으로 본 자리를 먼저 본다 (2026-11-09).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요): 놓친 뒤 반응 시간 동안은 마우스를 그대로 두고, 그 뒤 1초 동안 마지막 자리를 본다. 몬스터를 앞서 겨누는 각도는 실제 몸에서 20도까지다 (달려오는 멧돼지를 앞서 겨누면 마우스가 몸 근처·뒤쪽으로 튀어 시야가 멧돼지를 벗어났다).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요): 맞은 쪽은 0.8초 동안 본다. "맞은 쪽"은 네크로맨서를 노리는 가장 가까운 몬스터 쪽이다. 처음 보인 몬스터는 반응 시간이 지나야 겨누고, 겨눌 몬스터가 없으면 그 자리에 서서 둘러본다.
- **제안** (구현에는 이렇게 넣었다, 확인 필요):
  - 빛 없는 지형의 밝기는 원래 색의 0.4배. 나타나고 사라지는 시간 0.15초.
  - 빛 반지름(보는 거리)은 448px (화면 가운데에서 구석까지 약 367px). 둘레 원 바깥으로 8px에 걸쳐 어두워진다.
  - 상자·탈출 지점은 지형처럼 늘 보이고, 어둡게 칠해졌다가 빛을 받으면 밝아진다. 바닥 물건·시체·몬스터·몬스터의 탄은 보일 때만 보인다.
- 메모 (성능, 2026-11-10 측정, 3D 시야): 2배 맵 프레임 시간 중앙값은 플레이어 빛만 약 1.5ms, 언데드 8마리 2.1~2.8ms. 지역에 들어갈 때 시야 준비 47ms, 지형 생성 약 270ms.

## 조준점 — 확정

- 게임 화면 위에서는 마우스 커서가 조준점 그림으로 바뀐다. 반응이 빠르도록 시스템 커서를 바꾸는 방식으로 한다.
- 창 배율이 바뀌어도 게임 픽셀 크기와 맞도록, 배율마다 커서 그림을 따로 둔다.
- 인벤토리, 상자, 창고, 메뉴 위에서는 일반 화살표 커서로 돌아간다.
- 다음 공격까지 남은 시간은 조준점에 표시하지 않는다.
- **제안** (구현에는 이렇게 넣었다, 확인 필요):
  - 핫바 칸처럼 클릭을 받는 다른 UI 위에서도 화살표다. 체력 바·마나 바·뼈 개수 같은 장식용 HUD 위에서는 조준점 그대로다 (싸우다 화면 구석을 겨눌 때 커서가 바뀌지 않게).

## 몬스터와 드랍 — 확정

- 하위 몬스터를 잡으면 뼈를 떨어뜨린다. 개수는 몬스터마다 설정된 값을 따른다.
- 머리뼈는 몬스터에게서 일정 확률로 얻거나 파밍으로 얻는다.
- 몬스터는 일정 확률로 자기 머리뼈를 떨어뜨린다. 쥐는 50%다.
- 첫 하위 몬스터는 쥐다.
- 하위 몬스터는 네크로맨서에게 다가와 몸으로 부딪혀 공격한다.
- 각 몬스터는 자기 머리뼈를 떨어뜨린다. 머리뼈 확률은 몬스터가 죽을 때 정한다.
- 바닥에 떨어진 물건(버린 아이템)은 E를 눌러 줍는다.
- 주울 수 있는 물건이나 채집할 수 있는 시체 가까이 가면 안내 UI가 뜬다.

### 몬스터 타게팅

- 감지 범위 안에 누군가(네크로맨서·언데드) 있으면 가장 가까운 대상을 노린다. 벽이 가린 대상은 감지하지 못한다 (아래 "길찾기와 벽").
- 무리에 속하지 않은 몬스터: 감지 범위 안에 아무도 없을 때 공격을 받으면 공격한 대상을 노린다. 쫓아오다가 감지 범위에 누가 들어오면, 그때부터 가장 가까운 대상을 노린다. 무리원은 아래 "몬스터 무리"의 경보를 따른다.
- 쫓다가 포기하는 조건은 종마다 다르다 (사용자 결정, 2026-11-13. 2026-11-07의 공통 한계를 바꿈. 아래 "길찾기와 벽"):
  - 쥐·고블린 투석병·박쥐 (임시값): 대상과 350px보다 멀어지거나(보이든 안 보이든. 걸어서 도망칠 수 있게), 대상을 못 본 지 5초가 지나면 포기한다. 350은 기본 공격 사거리(300)보다 길게 둔 값이다 (사용자 결정, 2026-11-12. 250에서 올림. 사거리보다 짧으면 멀리서 반격 없이 쏠 수 있다). 다시 보면 못 본 시간은 처음부터 잰다.
  - 멧돼지 (임시값): 추격을 시작한 뒤 6초가 지나거나, 대상을 못 본 지 3초가 지나면 포기한다. 짧게 둔다. 거리가 아니라 시간으로 짧게 한 것은, 거리가 사거리(300)보다 짧으면 멀리서 반격 없이 쏠 수 있어서다. 예전의 "못 본 지 10초"는 지웠다.
    - 추격 시간은 대상이 감지 범위 밖이거나 안 보이는 동안만 잰다. 감지 범위 안에서 보이면(싸우는 중) 처음으로 돌아가고, 맞으면 처음부터 다시 잰다 (사용자 결정, 2026-11-14).
    - 그래서 벽 뒤로 3초 숨으면 떨쳐진다. 멧돼지는 모퉁이를 돌아서 쫓아오지 못한다 (우회에 약 7초가 걸린다 (2026-11-14 잰 값 7.4초). 사용자 결정, 2026-11-14: 값을 그대로 둔다).
  - "쫓기 시작한 자리에서 400px" 한계와 예전 150px 규칙은 지웠다 (사용자 결정, 2026-11-13). 박쥐 무리의 "싸움을 시작한 자리에서 150px"도 지웠다. 박쥐도 종별 조건을 쓴다 (사용자 결정, 2026-11-13). 박쥐(속도 100)는 걷기(80)보다 빨라서, 뛰어서 350px를 벌리거나 5초 숨어야 떨칠 수 있다.
  - 포기해도 원래 자리로 돌아가지 않는다. 포기한 그 자리에서 평소 행동을 한다. 체력 회복도 없다 (사용자 결정, 2026-11-13. 예전에는 맞기 시작한 자리로 돌아갔고, 다 돌아갈 때까지 대상을 바꾸지 않았다).
- 멧돼지는 다가가는 중에만 대상을 바꾼다. 예고·돌진·멈칫 중에는 처음 대상을 유지하고, 멈칫이 끝나면 다시 고른다.
- 박쥐 무리는 무조건 함께 싸운다. 한 마리라도 어그로가 끌리면 무리 전체가 그 대상 하나를 노린다. 각자의 감지·공격자 쫓기 판단보다 무리 대상이 먼저다 (사용자 결정, 2026-11-13: 박쥐만 지금처럼 대상 하나를 함께 노린다. 동시 돌진과 흩어져 돌기가 한 대상을 전제로 한다. 다른 무리는 아래 "몬스터 무리").
  - 무리 안에서 대상이 다르면 가장 최근에 어그로를 끈 대상을 노린다.
  - 무리 전원이 종별 추격 포기 조건을 넘으면 무리가 함께 포기하고, 그 자리에서 평소 행동을 한다. 둥지로 돌아가지 않는다 (사용자 결정, 2026-11-13. 예전에는 각자 무리 싸움을 시작한 자리로 돌아갔다).
  - "어그로가 끌림"은 맞았을 때(때린 쪽), 또는 노리는 대상이 없다가 새로 감지했을 때다. 이미 대상이 있는 박쥐의 "가장 가까운 대상"이 위치에 따라 바뀌는 것은 넣지 않는다 (무리가 계속 방향을 틀지 않게) (사용자 결정, 2026-11-14).
- 언데드에게는 이 규칙을 적용하지 않는다. 언데드의 타게팅은 아래 "언데드 능력치와 타게팅"을 따른다 (감지 범위가 없다).

### 몬스터 무리 (사용자 결정, 2026-11-13)

계획 전체와 구현 단계는 `docs/plans/2026-11-13_monster_pack_plan.md`에 있다. 구현은 그 계획의 단계를 따라 들어간다. 2026-11-14에 1-1단계(종별 추격 포기 조건, 돌아가지 않음), 1-2a단계(경보와 신호, 각자 대상 고르기, 시야 공유, 무리 단위 포기), 1-2b단계(함께 배회, 디버그 표시 F3)가 들어갔다. 공격권부터 아래는 아직 구현 전이다. 무리 규칙은 무리 시험 지역(`regions/test_pack.tscn`)에서 본다.

- 대부분의 몬스터는 무리로 다닌다. 무리는 평소에 함께 돌아다닌다. 다른 무리끼리는 돕지 않고 서로 싸우지도 않는다. 한 무리에 여러 종이 섞일 수 있다.
  - 무리 크기 (임시값): 쥐 큰 무리 6~8·낙오 패거리 3~4, 멧돼지 2~3, 투석병 2~3, 박쥐 3.
  - 함께 배회: 무리원은 무리 배회 기준점에서 64px(2칸, 임시값) 안에서 배회한다 (사용자 결정, 2026-11-14). 박쥐 무리는 함께 배회하지 않는다.
  - **제안** (구현에는 이렇게 넣었다, 확인 필요, 2026-11-14): 기준점은 3초마다 방향을 새로 고르고(30% 확률로 멈춤), 무리원 중 가장 느린 배회 속도의 0.6배로 움직인다. 64px 밖으로 나간 무리원은 기준점 쪽으로(벽은 돌아서) 돌아온다. 무리원이 따라오지 못하면(벽 등) 기준점이 무리 가운데에서 64px보다 멀어지지 않게 당긴다. 포기하면 기준점을 그 자리(무리 가운데)에 다시 둔다. 값은 `MonsterPack`의 "함께 배회" 묶음.
  - 무리 디버그 표시는 F3으로 켜고 끈다 (사용자 결정, 2026-11-14).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요, 2026-11-14): 디버그 표시는 바닥에 무리 색(팔레트의 주황·파랑·초록·보라·노랑·청록을 무리 순서대로)으로 그린다. 평소에는 무리원 발밑의 가는 고리, 배회 기준점까지 선, 기준점 둘레(64px). 신호 중에는 신호를 내는 무리원만 채운 원. 경보 중에는 굵은 고리와 노리는 대상까지 선. 박쥐 무리는 대상이 있으면 경보처럼 그린다. 개발 빌드에서만 켤 수 있다.
- 경보: 무리원 하나가 공격당하거나 감지하면 무리 전체가 경보를 낸다. 경보가 나면 네크로맨서와 모든 언데드가 무리의 적이 되고, 무리원은 그중에서 자기 타게팅 규칙(가장 가까운 대상)으로 고른다. 무리원이 본 적이 없는 언데드도 적이다 (사용자 결정, 2026-11-14. "무리가 본 적만 노린다"는 넣지 않는다). 맞았을 때와 감지했을 때 모두 신호 동작 뒤 경보가 난다 (사용자 결정, 2026-11-14).
  - 알아채는 방식은 종마다 다르다. 세부는 나중에 정하고, 지금은 종 공통의 임시 동작이다 (임시값: 0.3초 멈추고 깜빡임).
  - 무리원 하나라도 적을 보고 있으면 무리 전체가 그 위치를 알고 쫓는다. 아무도 적을 못 보는 동안에도 무리 없는 몬스터처럼 길을 따라 적의 실제 위치로 쫓다가, 못 본 시간 한계를 넘으면 포기한다 (사용자 결정, 2026-11-14. "마지막으로 본 위치로 간다"는 넣지 않는다. 찾기는 "몬스터 AI 개선" 2단계 몫).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요, 2026-11-14):
    - 신호 동작: 계기를 준 무리원이 신호 시간 동안 멈추고(밀려나는 것은 그대로) 몸 밝기 2배로 0.1초마다 깜빡인다 (`Monster`의 `alarm_blink_brightness`·`alarm_blink_interval`). 그림이 있는 몸(쥐)과 임시 도형 모두 같다. 맞아서 신호가 나면 맞은 번쩍임(0.1초)이 먼저 보이고 그 뒤 깜빡인다.
    - 신호는 처음 계기를 준 무리원 하나만 낸다. 신호 중에 다른 무리원이 맞거나 감지해도 신호를 다시 시작하지 않고, 그 적을 아는 적에 더하기만 한다. 신호를 내던 무리원이 죽으면 바로 경보다.
    - 무리원은 네크로맨서 편 전체 중 곧은 거리로 가장 가까운 적을 노린다 (길 거리가 아니다).
    - 경보 중에 무리원은 3프레임에 한 번씩 엇갈려 적을 본다 (`MonsterPack`의 `sight_check_interval`).
    - 신호·경보를 쓰지 않는 종(박쥐)은 데이터로 가른다 (`MonsterData.pack_one_target`). 무리 규칙은 무리의 첫 멤버 데이터로 정한다.
- 추격 포기: 무리원 모두가 자기 종의 포기 조건(위 "몬스터 타게팅")을 넘어야 무리가 함께 포기한다. 섞인 무리에서는 가장 긴 조건이 정한다. 포기한 무리는 그 자리에서 평소 행동을 한다.
- 무리는 거점에 들어오지 못한다. 거점 입구에서는 대상을 놓친 것으로 처리한다.
- 공격권: 대상 하나당 동시에 공격할 수 있는 수를 종마다 둔다. 쥐 2, 투석병 1, 멧돼지 1. 원거리 공격도 같은 공격권을 쓴다. 공격권은 대상마다 모든 몬스터가 함께 센다: 다른 무리나 무리 없는 몬스터도 같은 대상의 공격권을 나눠 쓴다 (사용자 결정, 2026-11-14).
  - 공격권이 다 차면 1초마다 기다리는 몬스터 중 하나를 무작위로 골라 추가 공격권을 준다. 추가 공격권은 공격 한 번만 쓰고 반납하며, 한 대상에 동시에 최대 1개다.
  - 공격권이 없는 몬스터는 대상 주변을 일정 거리로 맴돌며 기다린다 (임시값: 쥐 64px, 멧돼지 96px, 투석병 170px).
  - 반납: 공격이 끝날 때, 죽을 때, 대상이 바뀌거나 대상을 놓칠 때, 멀리 밀려날 때(임시값 48px 이상), 시간 제한이 지났을 때(임시값 4초).
  - 박쥐에는 공격권을 적용하지 않는다. 박쥐는 지금의 패턴(둥지, 박쥐 길, 동시 돌진)을 그대로 두고, 새 규칙 중 "돌아가지 않음"만 적용한다. 경보 신호 동작과 함께 배회는 넣지 않는다.
  - 무적 0과 시야 밖 공격으로 생기는 위험은 의도된 어려움으로 본다.
- 좁은 길목: 2칸 폭 이하의 좁은 칸이 길목이다. 길목 안에는 공격권(추가 공격권 포함)을 가진 몬스터만 들어간다. 나머지는 우회 길이가 직선 길의 1.5배 이하면 돌아가고, 아니면 길목 입구 밖에서 흩어져 기다린다. 길목 위치·대기 자리·우회 길이는 지형을 구울 때 미리 계산해 저장한다.
- 대장: 무리 생성 때 확률로 생긴다 (임시값 15%). 퀘스트를 받으면 다음 던전 입장 때 퀘스트 대상 무리에 확정으로 생기고, 퀘스트를 깨면 다시 확률로 돌아간다.
  - 대장이 살아 있는 동안 같은 무리원 공격력 +20%. 대장 자신은 체력 1.5배이고 대장임을 알 수 있는 표시가 있다. 대장이 죽으면 강화는 즉시 사라진다. 무리는 대장을 따라 움직이지 않는다.
  - 대장을 잡으면 높은 확률로 네임드 머리뼈를 준다 (임시값 70%). 네임드 머리뼈는 지금은 최소한의 임시로 만든다: 네임드 표시와 고정 이름 하나, 능력은 네임드 배율(120%)만. 아래 미정 "네임드"는 그대로다.
- 드랍: 한 번 들어가 얻는 몬스터 뼈의 기대값을 지금의 120%로 맞춘다 (얕은 굴 몬스터 뼈 100개 → 120개: 쥐 40, 멧돼지 32, 박쥐 12, 거미 자리의 임시 투석병 16. 지역 상자의 뼈는 넣지 않는다. 사용자 결정, 2026-11-14. 처음에 84 → 101로 적었던 것은 투석병을 빼먹은 계산이었다).
  - 마리당 뼈는 기대값으로 정한다. 정수 부분은 확정, 소수 부분은 확률로 준다 (예: 1.4 = 1개 + 40% 확률로 1개). 대장은 뼈를 더 주지 않는다.
  - 머리뼈 보정: 인벤토리, 소환 중인 언데드, 수리 기계 안을 모두 세서 머리뼈가 하나도 없을 때 쥐의 머리뼈 확률을 올린다 (임시값 50% → 80%). 보장은 없다.
- 초기화와 유지: 거점으로 돌아가면 던전의 몬스터는 모두 초기화되고, 다음 입장 때 새로 생긴다. 그 전까지 잡은 무리는 다시 생기지 않는다.
  - 던전 안 다른 지역에 갔다 돌아오면 몬스터 상태(위치, 체력, 무리 상태, 죽은 몬스터, 대장)는 유지된다.
  - 플레이어가 떠난 지역의 무리는 그동안 멈춰 있고, 쫓던 무리는 떠나는 순간 대상을 놓친 것으로 처리한다. 돌아오면 그 자리에서 평소 행동(배회)을 한다.
- 초반 지역에는 큰 쥐 무리에서 낙오된 3~4마리 쥐 패거리를 둔다. 적응하면 쉽게, 적응하지 못해도 고전 끝에 잡을 수 있게 맞춘다 (수치는 측정 후).
- 무리 규칙의 무작위(대장, 소수 뼈, 머리뼈 보정, 추가 공격권)는 시드 기반 난수를 쓴다 (테스트·측정 재현용).

- 1단계 구현됨 (수치는 첫 값). 전후 비교: `tests/balance/results/2026-11-09_ai_before_50runs.md`(전), `tests/balance/results/2026-11-09_ai_stage1_after.md`(후).
- 몬스터가 멍청해 보이는 문제(플레이어가 멈추면 몬스터도 서서 공격만 함)를 세 단계로 고친다. 1단계는 상태 흐름의 뼈대와 "싸움", 2단계는 "찾기", 3단계는 "평소"를 채운다.
- 모든 몬스터가 쓰는 상태: 평소 → 발견 → 싸움 → 찾기 → 돌아가기. 지금의 행동 조각(다가가기, 돌진, 던지기, 급강하)은 상태 안에 끼워진다. 1단계에서는 지금 동작(발견하면 쫓기, 추격 한계에서 포기)을 그대로 유지한다. 무리화(위 "몬스터 무리", 2026-11-13)로 돌아가기는 없어진다: 포기하면 그 자리에서 평소로 간다.
- 1단계 싸울 때 움직임 (아직 구현 전):
  - 공통: 대상이 공격 범위 안에 있어도 제자리에 멈춰 있지 않는다. 다만 프레임마다 방향이 튀어 떨리지 않게 한다. 몬스터끼리 한 점에 겹치지 않게 간격을 둔다 (언데드 간격 규칙 참고).
  - 쥐: 물고 나서 1~2칸 물러났다가 다시 들어온다. 대상 주위를 옆으로 돈다. 살아 있는 쥐만 그렇다 (쥐 언데드는 아래).
    - **제안** (구현에는 이렇게 넣었다, 확인 필요): 물러나는 거리 40, 속도 40, 멈춤 0.25초, 들어올 때 옆으로 도는 거리 56·비율 0.75, 곁에서 기다릴 때 도는 속도 30 (`data/behaviors/approach_hit_and_run.tres`). 몬스터끼리 떨어지려는 거리 24 (쥐).
    - 쥐 기준 (사용자 결정, 2026-11-09): 잡는 시간 보통 8.2초·초보 13.6초 이내 (지금의 +20%), 쥐에게 죽는 비율은 모든 실력에서 0%. 기준을 넘으면 수치를 맞추기 전에 사용자에게 먼저 알린다.
    - 물러난 뒤 잠깐 멈추는 틈을 넣어서, 쥐를 잡는 시간이 지금보다 크게 늘지 않게 한다 (사용자 요청, 2026-11-09). 구현할 때 잡는 시간과 쥐 언데드 대결(`run_undead_duel.gd`)을 지금 값과 비교한다. 지금 값은 `tests/balance/results/2026-11-09_ai_before_50runs.md`.
  - 멧돼지: 돌진이 끝나면 대상 옆에 서 있지 않고 방향을 틀어 다시 거리를 벌린다 (돌진할 거리를 만들려고).
    - **제안** (구현에는 이렇게 넣었다, 확인 필요): 멈칫 뒤 대상에게서 120도 이상 등을 돌린 8방향 중 벽까지 여유 있는 쪽을 무작위로 골라, 대상과 96px 벌어질 때까지(최대 2.5초) 걷는다. 방향은 한 번만 정한다. 몬스터끼리 떨어지려는 거리 32.
    - 언데드 멧돼지도 거리를 벌린다 (사용자 결정, 2026-11-09). 언데드 멧돼지가 멀어져 적 멧돼지가 네크로맨서를 더 노리는 대가가 있다: 멧돼지 + 언데드 멧돼지 1 + 네크로맨서에서 네크로맨서 사망 10% → 28% (`tests/balance/results/2026-11-09_ai_stage1_causes.md`).
  - 박쥐: 지금의 흩어져 돌기가 이 역할을 한다 (바꾸지 않음. 확인: 도는 동안 제자리에 서 있지 않다, `scenario_monster_combat.gd`).
  - 고블린 투석병: 던지는 사이사이 옆으로 비켜 선다. 던질 때 잠깐 멈춘다 (사용자 결정, 2026-11-09). 물러나는 속도 40은 그대로 둔다. 물러나다 벽에 막히면 벽을 따라 미끄러지지 않고 방향을 틀거나 멈춘다 (사용자 결정, 2026-11-09).
    - **제안** (구현에는 이렇게 넣었다, 확인 필요): 던진 뒤 멈춤 0.4초, 옆걸음 속도 30(도는 쪽은 던질 때마다 정함), 벽을 보는 거리 12, 트는 각도는 45도까지 (`data/behaviors/throw.tres`). 몬스터끼리 떨어지려는 거리 32.
    - 이유: 고블린이 물러나는 속도(40)가 쥐 언데드 속도(40)와 같아 쥐 언데드가 고블린을 한 대도 못 때렸다 (보통 50판). 테스트 안에서 물러나기를 끄면 죽음 28% → 0%, 잡는 시간 17.5초 → 11.2초.
  - 뒷걸음 공통 배율은 두지 않는다 (사용자 결정, 2026-11-09). 쥐·멧돼지가 물러나는 속도는 각자 데이터에 둔다.
  - 쥐 언데드는 물러나지 않고 계속 붙어서 싸운다 (사용자 결정, 2026-11-09. 살아 있는 쥐와 언데드 쥐를 움직임으로 구별한다). 같은 행동 코드에 데이터(`hit_and_run`)로 켜고 끈다.
  - 값(물러나는 거리, 도는 속도, 간격 등)은 모두 데이터로 둔다.
- 작업은 `vision`에서 딴 `monster-ai` 브랜치에서 한다 (사용자 결정).

### 몬스터 종류와 등급

- 몬스터마다 적일 때의 행동과 언데드일 때의 행동이 있다. 언데드는 기본적으로 적일 때와 같은 행동을 한다.
- 행동은 "다가가기", "돌진하기", "거리 두고 쏘기" 같은 조각으로 나뉘고, 몬스터와 언데드가 같은 조각을 골라 쓴다.
- 몬스터에는 등급이 있다 (언데드 등급 체계와는 별개다).
  1. 혼자 잡을 수 있음: 혼자 쉽게 잡는다.
  2. 언데드가 있어야 함: 혼자도 잡을 수 있지만 위험하다. 언데드는 안전을 위해 쓴다.
  3. 강한 언데드가 필요함: 혼자서는 거의 못 잡는다. 언데드가 필수다. (방법은 3등급을 만들 때 정한다)
- 이번에 추가할 몬스터: 멧돼지(돌진 짐승), 박쥐, 고블린 투석병(원거리). 멧돼지부터 하나씩 만든다.
- 시험 지역은 등급별 구역으로 배치한다. 시작점 근처가 1등급이고, 안쪽으로 갈수록 등급이 높다.

| 몬스터 | 등급 |
|---|---|
| 쥐 | 1. 혼자 잡을 수 있음 (기본 공격 7대에 죽는다: 지금 기본 공격 피해 1 → 체력 7) |
| 멧돼지 | 2. 언데드가 있어야 함 |
| 박쥐 | 2. 언데드가 있어야 함 (작지만 빨라서 맞히기 어렵다, 체력 8) |
| 고블린 투석병 | 2. 언데드가 있어야 함 (거리를 두고 물러나며 던져서 혼자 쫓기 힘들다) |

### 멧돼지

- 돌진 거리 안에 들어올 때까지 대상에게 다가가기만 한다. 공격은 돌진뿐이다.
- 돌진 거리 안에 들어오면 예고 → 돌진 → 멈칫을 반복한다.
- 예고: 제자리에 멈춰 힘을 모으며 깜빡이고, 바닥에 돌진 방향 선을 보여준다.
  - 모으는 동안 선은 대상을 따라 돌고, 예고가 끝나기 잠깐 전에 방향이 고정된다.
- 돌진: 고정된 방향으로, 돌진을 시작할 때 노린 대상이 있던 자리를 지나 일정 거리(임시값 40px)까지 달린다. 벽에 부딪히면 그 자리에서 끝난다.
  - 언데드를 노린 돌진이 그 뒤의 네크로맨서까지 오지 않게 하려는 것이다 (밸런스 측정에서 언데드가 있으면 오히려 더 위험했다).
  - **제안**: 한 번 돌진하는 최대 거리는 따로 둔다 (임시값 170px). 멀리 있는 대상에게 끝없이 달려가지 않게.
- 돌진이 끝나면 잠깐 멈칫한다(때릴 기회).
- 돌진에 맞으면 큰 피해를 받고 밀려난다. 한 번 돌진에 같은 대상은 한 번만 맞는다. 지나가며 네크로맨서와 언데드를 둘 다 칠 수 있다.
- 돌진은 몸에 막히지 않는다. 몸에 닿으면 뚫고 지나간다.
- 구르기 무적 중에 돌진에 닿으면 피해는 없고 밀려나기만 한다.
- 벽에 막혀 돌진할 수 있는 거리가 64px(2칸)보다 짧으면 돌진하지 않고, 대상에게서 물러나 거리를 벌린 뒤 돌진한다 (2026-11-08 바꿈. 처음에는 다가가기를 계속하게 했더니, 2칸 길목에 낀 멧돼지가 공격 없이 길만 막았다). 예고를 시작할 때와 돌진을 시작할 때 실제 몸 모양으로 잰다. 길목에 끼인 멧돼지가 제자리 돌진으로 붙어 있는 언데드를 함께 치던 문제 때문이다 (2026-11-08).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요): 예고를 다 마쳤는데 고정된 방향이 막혀 있으면 돌진하지 않고 바로 다시 다가간다 (멈칫 없음).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요): 물러나는 방향은 8방향 중 대상 쪽이 아닌(대상 방향과 90도 이상) 방향에서 벽까지 가장 멀리 갈 수 있는 쪽이다. 속도는 이동 속도와 같다. 어느 쪽으로도 갈 수 없으면 그 자리에 선다. 대상이 64px보다 가까운데 "벽이 가로막음"으로 나오면(몸이 벽에 닿아 생기는 잘못된 판단) 돌아서 다가가지 않고 물러난다. 한 번 물러나기 시작하면 대상과 96px(`back_off_distance`, 임시값) 떨어질 때까지 이어 간다 (64px 경계에서 물러나기·다가가기를 번갈아 하며 흔들리지 않게). 벽까지 거리는 몸이 벽에 살짝 닿아 있어도 떼어 낸 뒤 잰다.
- 돌진은 방향과 상관없이, 돌진하는 동안 몸 가까이 닿은 상대를 맞힌다.
  - "돌진 방향 앞쪽에 있는 상대만 맞힌다"(B)는 넣지 않는다 (사용자 결정, 2026-11-08). 멧돼지에 붙어 싸우던 쥐 언데드 둘이 한 번에 함께 죽던 문제는 쥐 언데드 공격 거리 24(A, 아래 "언데드 능력치와 타게팅")로 해결한다.
  - 측정 (1배 맵, 멧돼지 잡으러 + 쥐 언데드 2, 실력마다 50판): A만 넣어도 A+B와 거의 같았다. 함께 죽은 판 0, 끝까지 싸울 때 죽은 비율 10 / 56 / 86% (숙련 / 보통 / 초보), 잡은 멧돼지 3.3 / 2.6 / 1.4.
  - 데이터에는 켜고 끌 수 있게 남겨 둔다 (돌진 행동의 `front_only_hit`, 기본 끔).
- 언데드 멧돼지도 예고와 방향 선을 보여주되 선 색을 적과 다르게 한다. 언데드의 돌진은 몬스터만 친다.
- **검토 중** (2026-11-10): 피할 수 있는 시간을 정하는 것은 예고 길이가 아니라 방향 고정 시간(`lock_time`)이다. 멧돼지 난이도 조정은 방향 고정 시간으로 한다.
  - 근거: 봇의 반응 시간을 방향 고정부터 재는 임시 측정에서 멧돼지 혼자·보통 실력의 죽음이 예고만 +0.2초면 74% 그대로, 고정 시간까지 +0.2초면 74% → 0%였다 (`tests/balance/results/2026-11-10_bot_dodge_plan.md`). 사람에게도 같은지는 직접 해 봐야 안다.

### 박쥐

- 크기는 작은 몬스터(16×16)다. 크기 대신 속도로 위험을 보여준다 (`docs/art-direction.md`의 예외).
- 3마리 무리로 나온다. 무리는 어그로를 공유하고 대상 하나를 함께 노린다 (몬스터 타게팅의 "박쥐 무리").
- 날아다닌다. 몸끼리는 겹쳐 지나가고(네크로맨서·언데드·다른 몬스터), 벽에는 막힌다.
  - 날아다니는 몸은 별도의 충돌층(flying)을 쓴다. 벽하고만 부딪히고, 네크로맨서의 탄은 맞는다. 언데드 박쥐도 같다.
- 싸우는 순서: 짧은 예고(멈칫 + 깜빡임) → 앞으로 빠르게 돌진해 한 번 문다 → 다시 멀어진다 → 그 거리를 유지하며 돈다 → 일정 시간 돌고 나면 다시 예고부터.
  - 물고 빠질 때가 때릴 기회다.
  - 돌 때는 노리는 대상 주변을 돌되, 네크로맨서와 모든 언데드와 일정 거리 이상을 유지한다 (가까운 쪽에서는 바깥으로 비켜 돈다).
  - 돌진할 대상은 몬스터 타게팅 규칙을 따른다.
  - 돌진 방향은 돌진을 시작하는 순간 대상이 있던 쪽으로 고정되고 곧게 날아간다. 최대 거리까지 물지 못하면(빗나가면) 그대로 물러난다.
  - **검토 중** (2026-11-10): 지금은 방향이 날아가는 순간 정해져서 피하기가 방향 찍기가 된다. 예고하는 동안 방향을 고정하고 화면에 보여주는 안을 검토한다 (바라보는 방향, 짧은 선 표시 등. 방식은 나중에 선택지로 묻는다).
  - 물러날 때는 대상의 반대쪽으로, 도는 반경까지 물러난다.
  - 도는 방향(시계 / 반시계)은 박쥐마다 무작위다.
- 물기는 작은 피해만 준다. 특별한 효과는 없다.
- 언데드 박쥐도 같은 행동을 한다 (몬스터를 물고, 몬스터들과 거리를 유지하며 돈다).
- 목표: 잡기는 어렵지 않지만 삐끗하면 실패하는 몬스터. 따로 조금씩 무는 것만으로는 실수해도 위협이 없었다.
- **무리 동시 돌진**: 무리가 함께 예고한 뒤 세 마리가 한꺼번에 파고든다.
  - 예고: 무리 전체가 제자리에 멈춰 깜빡인다. 0.4초 (임시값, 처음 0.8초는 걷기만 해도 피해져서 줄임). 방향 선은 없다.
  - 돌진 방향은 날아가는 순간 대상이 있던 쪽으로 정한다 (미리 고정하지 않는다). 걷기로는 피하지 못하고, 날아오는 순간 구르면 무적으로 피한다.
  - 제때 구르면 피할 수 있어야 한다.
  - 싸우는 동안 6초마다 한다 (임시값).
  - 평소의 따로 치고 빠지기는 그대로 두되 덜 자주 한다 (도는 시간 2초 → 4초, 임시값).
  - 무리 중 일부가 죽어도 싸우는 박쥐가 2마리 이상이면 남은 박쥐끼리 한다. 1마리만 남으면 평소 치고 빠지기만 한다.
- **무리는 무조건 함께 싸운다**: 한 마리라도 어그로가 끌리면 무리 전체가 그 대상을 노린다 (자세한 규칙은 위 "몬스터 타게팅"). 포기하면 그 자리에서 평소 행동을 하고 둥지로 돌아가지 않는다 (사용자 결정, 2026-11-13).
- **제안** (구현에는 이렇게 넣었다, 확인 필요):
  - 6초가 되었을 때 자기 공격(예고·돌진·물러나기) 중인 박쥐가 있으면, 모두 끝날 때까지 기다렸다 시작한다.
  - 싸우는 박쥐가 2마리보다 적어지면 6초를 처음부터 다시 잰다.
  - 동시 돌진의 물기 피해는 평소 물기와 같다 (마리당 1.5).
  - 언데드 박쥐는 동시 돌진을 하지 않는다 (무리가 아니다).
- **무리가 흩어져 돌기** (붙어서 같은 방향으로 돌면 위협적이지 않아서):
  - 무리의 박쥐는 대상 주위에 간격을 두고 나눠 자리 잡고 돈다 (3마리면 약 120도씩). 박쥐가 줄어들면 남은 박쥐끼리 다시 간격을 나눈다.
  - 박쥐마다 자기 구역(3마리면 120도) 안에서 자기 방향으로 돌다가 구역 끝에서 방향을 바꾼다. 구역들은 무리 전체가 천천히 돈다 (한 바퀴 약 12초, 임시값).
  - 박쥐마다 도는 방향과 도는 거리가 다르다. 도는 거리는 50~75 사이 무작위 (임시값).
  - 도는 동안 속도와 방향이 약하게 불규칙하게 흔들린다: 속도 ±15%, 방향 ±10도 (임시값).
  - 박쥐끼리 32px 이상 떨어지려 한다 (임시값).
  - 동시 돌진은 각자 자리에서 한꺼번에 들어온다 (여러 방향에서).
  - 동시 돌진 때 박쥐 사이 빈틈은 그대로 둔다. 120도 간격이면 두 박쥐 사이로 구르면(64px) 돌진 줄에서 약 55px 벗어난다. 박쥐 쪽이나 그 반대쪽 줄을 따라 구르면 물린다.
- **제안** (흩어져 돌기, 구현에는 이렇게 넣었다, 확인 필요):
  - 구역 끝까지 다 쓰지 않고 구역 폭의 80%만 오간다 (이웃과 겹치지 않게).
  - 동시 돌진 때가 되면 혼자 예고하지 않고 자기 자리(구역 가운데, 자기 반경)로 곧장 날아간다(물러나는 속도 150). 모두 구역 가운데에서 20도 안에 오면 예고를 시작하고, 1.5초가 지나도 다 못 모이면 그냥 시작한다.
    - 이유: 대상이 원을 그리며 움직이면 도는 속도로는 자리를 따라잡지 못해, 동시 돌진이 한 판에 2.5번에서 0.8번으로 줄었다.
  - 자리 번호는 박쥐들이 지금 대상 주위에 있는 각도 순서대로, 모두가 덜 움직이는 쪽으로 정한다.
  - 처음 싸움에 들어갈 때 구역의 기준은 첫 박쥐가 있는 쪽이다.
  - 동시 돌진이 끝나면 박쥐마다 처음 정한 도는 방향으로 돌아간다.
  - 언데드 박쥐도 도는 거리와 흔들림은 박쥐마다 다르다 (구역은 없다).

### 고블린 투석병

- 거리를 두고 돌을 던진다 (2026-11-09 바꿈). 포물선은 그림만이고 돌은 곧게 날아간다. 던지기 직전 잠깐 멈추는 것이 유일한 예고다.
  - 돌마다 던지는 순간의 대상 위치와 속도로 도착 시점의 자리를 예측해 던진다. 곧게 걸으면 맞고, 던진 뒤 방향을 바꾸면 피할 수 있다.
  - 네크로맨서의 평타는 플레이어가 조준하므로 예측하지 않는다.
- 돌은 벽, 네크로맨서, 언데드에 맞으면 멈춘다. 다른 몬스터 몸에도 막힌다 (피해 없음). 도중에 안 막히고 그림자 자리에 도착하면 원 안의 가장 가까운 대상 하나가 맞고, 아무도 없으면 사라진다 (사용자 결정, 2026-11-09).
- 떨어질 곳에 그림자 원을 돌마다 하나 그린다. 시야와 상관없이 항상 보인다 (사용자 결정, 2026-11-09. "부채꼴 밖의 예고는 안 보인다"의 예외).
- 던지기 전과 던진 뒤 모두 멈춘다 (사용자 결정, 2026-11-09). 쥐도 물기 직전 멈춘다. 멈춘 사이 대상이 공격 거리를 벗어나면 물지 않는다.
  - 쥐 언데드의 물기 전 멈춤은 0이다 (사용자 결정, 2026-11-10). 이 멈춤은 플레이어가 읽으라고 주는 예고라서, 적이 읽지 않는 언데드에게는 필요 없다. 살아 있는 쥐는 멈춤을 유지한다.
  - 언데드 투석병의 던지기 전 멈춤과 던진 뒤 멈춤도 0이다 (사용자 결정, 2026-11-13). 쥐 언데드와 같은 까닭이다. 적 투석병은 그대로 멈춘다. 둘 다 멈추면 적 투석병과 언데드 투석병이 같은 박자로 던져, 돌마다 상대가 멈춘 순간(속도 0)을 노리고 빗나가서 싸움이 끝나지 않았다 (`scenario_projectile` 2마리 싸움이 30초 넘게 굳음. 언데드 투석병만 두 멈춤을 0으로 둔 실험에서는 시드 8개 모두 2.7~15초에 끝남).
- 한 번에 던지는 돌 수, 돌 사이 간격, 돌마다의 예측 비율과 오차는 데이터다 (사용자 요청, 2026-11-09). 연달아 던지는 동안 고블린은 멈춰 있다. 기본은 1발이다.
  - 3발은 실제 데이터에 넣지 않는다 (사용자 결정, 2026-11-10). 나중에 다시 잴 때는 돌 사이 간격을 구르기 무적(0.2초)보다 긴 0.35~0.5초로 잰다. 0.15초는 한 번 구르기로 다 피해져서 연달아 던지는 의미가 없다.
- **제안** (구현에는 이렇게 넣었다, 확인 필요): 예측 비율 0.8, 오차 ±6도 (적·언데드 같음), 적 투석병의 던지기 전 멈춤 0.3초·던진 뒤 멈춤 0.4초, 살아 있는 쥐의 물기 전 멈춤 0.1초, 그림자 반지름 12, 포물선 높이 24, 돌 속도 160.
- **제안** 투사체 도착 시간 (걷는 거리는 속도 80 기준):

| 거리 | 평타 (속도 800) | 고블린 돌 (속도 160) | 돌이 도착할 때까지 걷는 거리 |
|---|---|---|---|
| 64 | 0.08초 | 0.40초 | 32 |
| 100 | 0.13초 | 0.63초 | 50 |
| 140 | 0.18초 | 0.88초 | 70 |

- 던지는 거리 밖이면 다가오고, 가까이 오면 느리게 물러나면서 계속 던진다.
- 2마리가 근접 몬스터와 섞여 나온다. 근접 몬스터와 한 무리에 섞일 수 있다 (사용자 결정, 2026-11-13, 위 "몬스터 무리"). 시험 지역에서는 멧돼지 구역 뒤쪽에 둔다.
- 수치 (임시값): 체력 6, 돌 피해 2, 던지는 거리 140, 2초마다, 돌 속도 160, 물러나는 거리 90·속도 40, 이동 속도 45, 감지 150.
- 드랍·비용 (임시값, 박쥐와 같은 수준): 뼈 2, 머리뼈 30%, 첫 소환 뼈 5·마나 4, 유지비 초당 1.3, 죽은 판정 내구도 3.
- 언데드 투석병의 돌은 몬스터에게만 피해를 주고, 네크로맨서와 언데드는 지나간다 (네크로맨서 뒤에서 던져도 막히지 않게). 벽과 몬스터에는 멈춘다 (사용자 결정, 2026-11-13).
- **제안** (구현에는 이렇게 넣었다, 확인 필요):
  - 언데드 투석병의 수치 (실제 데이터에 맞게 고침, 2026-11-13. 예전에는 체력 4, 이동 속도 60, 감지 150, 피해 2로 적혀 있었다): 체력 5.1 (6 × 기본 배율 0.85), 이동 속도 45 (원래 몬스터와 같음), 던지는 거리 140, 피해 1 (2 × 공격력 배율 0.5, 아래 "언데드 능력치와 타게팅"), 2초마다. 언데드는 감지 범위를 쓰지 않고 계기로만 싸운다.
  - 돌 속도 160: "예고 없음" 선택지에는 예로 120을 적었지만, 수치 선택지의 160을 넣었다.

## 시체와 채집 — 확정

- 적을 죽이면 아이템이 바로 떨어지지 않고 시체가 남는다. 언데드가 잡아도 같다.
- 시체 가까이에서 E를 누르면 채집한다. 채집 한 번에 아이템을 한 종류씩 얻는다. 얻은 아이템은 바로 인벤토리에 들어간다.
- 채집하는 아이템은 시체에 남은 것 중에서 무작위로 고른다.
  - 인벤토리에 넣을 수 있는 것 중에서만 고른다. 넣을 수 있는 것이 없으면 채집이 시작되지 않고 "인벤토리 가득 참"을 보여준다.
  - 인벤토리에 자리가 없는 종류는 채집할 수 없고, 시체에 남는다.
- 시체 안에 무엇이 남았는지는 미리 보이지 않는다.
- 채집은 시간이 걸린다. 진행 상황은 탈출 게이지와 같은 화면 아래 자리에 게이지로 보여준다. 둘이 같이 보이면 위아래로 나란히 둔다.
- 채집 시간 = 몬스터마다 정한 기본 시간 × 아이템 종류의 배율. 머리뼈의 배율은 항상 다른 아이템보다 크다. 값은 임시값이다.
- 채집 중에 움직이거나(구르기 포함) 피해를 받으면 취소된다.
- 채집 중에 인벤토리를 열어도 채집은 계속된다.
- 채집은 네크로맨서만 한다.
- 다 채집한 시체는 빈 시체로 남고 색이 바뀐다. 빈 시체는 E 대상이 아니다.
- 근처에 시체와 바닥 물건이 같이 있으면 E는 더 가까운 것을 대상으로 한다.
- 시간 압박 장치(시체가 사라짐, 몬스터 재등장, 채집 소리)는 지금은 넣지 않는다.

## 머리뼈 — 확정

- 머리뼈는 종류가 매우 다양하다. 각 머리뼈는 특정 몬스터의 언데드를 소환한다.
- 첫 머리뼈는 "쥐의 머리뼈"다.
- 머리뼈에는 내구도가 있다. 내구도가 내려갈수록 그 머리뼈로 소환한 언데드의 능력치가 내려간다.
- 내구도가 0이 되면 그 머리뼈로 소환할 수 없다 (파괴되지는 않는다). 소환 중에 0이 되면 그 자리에서 일반 해제된다.
- 드물게 **이름이 있는 머리뼈**가 나온다.
  - 일반: "전사의 머리뼈" / 네임드: "전사 XXX의 머리뼈"
  - 네임드 머리뼈는 네임드 언데드를 소환한다.
  - 네임드 언데드는 일반 언데드보다 능력치가 조금 더 높다.

## 수리 기계 — 확정 (2026-11-11)

- 거점에 머리뼈 내구도를 채우는 수리 기계가 있다. 지역에는 없다.
- 기계 근처에서 F를 누르면 기계 전용 창이 열린다. 창고처럼 인벤토리(가운데 왼쪽)와 나란히 오른쪽에 뜬다.
  - 인벤토리의 머리뼈를 창의 칸에 끌어 놓고 "수리하기" 버튼을 누른다.
- 비용은 뼈다. 뼈 1개당 내구도 1을 채운다. **임시**: 비용은 나중에 언데드 강화 아이템과 함께 정한다 (사용자 결정, 2026-11-12. 기계 노드의 `cost_item`, `durability_per_item` 값).
- 뼈가 모자라면 가진 뼈만큼 일부 수리한다 (체력 회복과 같은 규칙).
- 소환 중인 머리뼈는 수리할 수 없다. 버튼이 회색이 되고 "소환 중"을 보여준다.
- **제안** (구현에는 이렇게 넣었다, 확인 필요):
  - 칸은 핫바처럼 머리뼈를 가리키기만 한다. 머리뼈는 인벤토리에서 빠지지 않고 핫바 등록도 그대로다. 칸을 우클릭하면 칸에서만 빠지고, 머리뼈가 인벤토리에서 사라지면(버림, 창고로 옮김) 칸이 빈다.
  - 창에는 머리뼈 이름, 내구도, "필요한 뼈 N개 (가진 뼈 M개)"를 보여준다. 쓸 수 없으면 버튼이 회색이고 이유(소환 중, 내구도 가득, 뼈 부족)를 아래에 적는다.
  - 모자란 내구도가 소수(예: 2.5)면 필요한 뼈는 올림한다.
  - 내구도 0인 머리뼈도 수리할 수 있다 (수리하면 다시 소환할 수 있다).
  - 창고 칸의 머리뼈는 칸에 넣을 수 없다 (인벤토리에 꺼내서 수리한다).
  - Esc·Tab을 누르거나 기계에서 멀어지면 창과 인벤토리가 함께 닫힌다.
  - 기계는 거점 오른쪽 위(창고 상자의 반대편)에 둔다. 그림이 생기기 전까지 임시 도형(몸통 5a6988, 윗면 feae34)이다.

## 소환 재료 — 확정

- 강한 몬스터의 언데드일수록 필요한 재료가 많아진다.
- 고급 언데드는 일반 뼈를 더 많이 쓰거나, 뼈를 조합해 만든 재료(예: 굵은 뼈)를 요구한다.

## 마나 — 확정

- 마나는 자연 회복된다.
- 최대 마나는 40이다 (20에서 늘림: 멧돼지 언데드가 유지비로 금방 해제되었다).
- 언데드 유지비: 소환 중인 언데드마다 초당 마나가 든다. 값은 몬스터 데이터에 있다 (지금 값은 임시값이다).
- 마나 바에 초당 변화량을 숫자로 보여준다. 차고 있으면 +숫자, 줄고 있으면 -숫자다.
  - 자연 회복과 유지비처럼 계속 일어나는 변화만 넣는다. 소환처럼 한 번에 쓰는 마나는 넣지 않는다.
  - 변화가 없을 때(가득 차 있고 언데드도 없을 때)는 숫자를 숨긴다.
  - 가득 찬 채 언데드가 있으면, 마나가 실제로는 안 변해도 "자연 회복 - 유지비" 계산값을 보여준다 (언데드를 더 띄워도 되는지 보이게).
- 소환할 때도 마나를 쓴다. 뼈·머리뼈는 재료이고, 소환 마나는 다시 소환하는 템포 비용이다.
- 마나가 0이 되면 언데드가 전부 한꺼번에 사라진다(디스폰).
- 기본 공격은 처음에는 마나를 쓰지 않는다. 업그레이드할수록 마나 소모와 피해량이 같이 늘어난다.
- 강화된 공격을 쓸 마나가 부족하면, 마나가 자연 회복될 때까지 기다리거나 마나 회복 아이템 등을 써야 한다.

## 뛰기·구르기·스태미나 — 확정

- 스태미나는 뛰기와 구르기에만 쓴다.
- 뛰거나 구르는 동안은 스태미나가 줄고 회복되지 않는다. 끝나면 다시 차오른다.
- Shift를 누르고 있으면 뛴다. Space를 누르면 구른다.
- 구르는 방향은 이동 방향이다. 멈춰 있으면 마우스 방향으로 구른다.
- 구르기 시간의 앞부분 일부만 무적이다.
- 스태미나가 부족하면 뛰거나 구를 수 없다.
- 스태미나 바는 네크로맨서 바로 오른쪽에 도넛 모양으로 있다.
  - 12시 방향에서 시계 반대 방향으로 줄어든다. 다시 찰 때는 줄어든 끝이 시계 방향으로 되돌아오며 찬다.
  - 가득 차면 숨긴다.
- 언데드는 따라갈 때 적어도 네크로맨서가 걷는 속도로 따라간다. 네크로맨서가 뛸 때는 멀리 떨어져 따라가는 중일 때만 네크로맨서의 뛰는 속도까지 빨라진다. 싸울 때는 원래 몬스터의 속도다.
- 수치(뛰기 속도, 구르기 거리·시간, 무적 시간, 스태미나 양, 소모량, 회복 속도, 언데드가 빨라지는 거리, 연속 구르기 비용·시간, 회복 지연)는 임시값이다.
- 0이 될 때까지 뛰면 지친다. Shift를 뗐다가 다시 눌러야 다시 뛸 수 있다 (0 근처에서 뛰기와 회복이 번갈아 일어나 걸음이 떨리는 것을 막는다).
- 뛰기는 Shift를 누르고 움직일 때만이다. 멈춰서 Shift만 누르고 있으면 스태미나가 줄지 않는다.
- 구르기는 시작할 때 비용을 한 번에 쓴다. 비용보다 적게 남아 있으면 구를 수 없다.
- 구르기 난사를 막는다. 한 번 구르는 것은 가볍게 두고, 연속으로 구르는 것만 제약한다. 굴러서 이동하는 것 자체는 막지 않는다.
  - 짧은 시간 안에 연속으로 구르면 구르기 비용이 점점 커진다 (임시값: 연속으로 보는 시간 1.0초, 비용 25 → 40 → 60).
  - 구른 뒤 일정 시간 동안 스태미나가 회복되지 않는다 (임시값: 0.6초).
  - 연속으로 보는 시간과 회복 지연은 구르기가 끝난 순간부터 잰다. 세 번째를 넘겨 계속 구르면 마지막 비용을 유지한다.
  - 메모: 지금 최대 스태미나(100)로는 25 + 40 뒤 35가 남아 세 번째(60)를 구를 수 없다. 사실상 연속 2번까지다 (그대로 두기로 함).
- 구르기도 이동이라 인벤토리가 열려 있어도 구를 수 있다. 인벤토리나 메뉴가 열려 있어도 Space는 구르기만 하고 버튼을 누르지 않는다.

## 인벤토리 — 확정

- Tab을 누르면 인벤토리가 열리고, 다시 누르면 닫힌다.
- 인벤토리 화면은 항상 화면 가운데 왼쪽에 뜬다.
- 인벤토리는 정해진 수의 칸이 있다. 지금은 10칸이다. 칸 수는 데이터로 두어 나중에 늘릴 수 있게 한다.
- 빈 칸도 항상 보인다. 물건은 들어간 칸 위치를 유지한다.
- 뼈도 칸을 차지한다. 뼈는 한 칸에 개수 제한 없이 쌓인다. 뼈 칸이 있으면 칸이 가득 차 있어도 뼈는 주울 수 있다.
- 머리뼈는 한 칸에 하나씩 들어간다.
- 열려 있어도 게임은 멈추지 않는다. 열려 있는 동안 네크로맨서는 이동만 할 수 있고 공격과 줍기는 막힌다.
- 머리뼈 칸 안의 아래쪽에 내구도 바가 항상 보인다. 현재 내구도 / 최대 내구도 비율만큼 채워진다.
- 칸이 가득 차면 줍지 못하고, 줍기 안내에 "인벤토리 가득 참"을 표시한다.
- 칸에서 우클릭하면 바로 버리지 않고, 그 칸 오른쪽에 메뉴가 뜬다. 화면 오른쪽 끝이라 공간이 없으면 왼쪽에 띄운다.
  - 메뉴 항목은 아이템 종류에 따라 다르다. 머리뼈: 회복하기, 뼈 제거, 핫바에 등록, 버리기 / 뼈: 버리기
  - 핫바에 등록: 빈 핫바 칸에 넣고, 빈 칸이 없으면 선택된 핫바 칸을 바꾼다.
    - 이미 핫바에 있는 머리뼈에는 "핫바에 등록" 대신 "핫바에서 빼기"가 보인다. 핫바 칸 우클릭처럼 핫바에서만 빠지고 머리뼈는 인벤토리에 남는다.
    - 소환 중인 머리뼈를 빼면 일반 해제되므로 "소환이 해제됩니다" 경고를 노란색으로 붙인다.
  - 회복하기는 핫바 + R과 같은 회복 규칙을 쓴다.
  - 지금 쓸 수 없는 항목은 회색으로 보여주고 이유를 같이 적는다 (예: 뼈 부족, 소환 중, 체력 가득).
  - 소환 중인 머리뼈의 버리기에는 "죽은 판정이 됩니다" 경고를 붙인다.
  - 메뉴는 바깥을 클릭하거나, Esc를 누르거나, 인벤토리를 닫으면 닫힌다.
  - 메뉴를 누른 클릭은 공격으로 나가지 않는다.
- 버리기는 그 칸의 물건을 통째로 네크로맨서 발밑에 버린다. 버린 물건은 다시 주울 수 있다.
- 칸에 있는 물건을 마우스로 끌어서 다른 칸에 놓을 수 있다.
  - 빈 칸에 놓으면 그 칸으로 옮겨진다.
  - 물건이 있는 칸에 놓으면 두 물건의 자리가 바뀐다.
  - 인벤토리 바깥에 놓으면 취소되고 원래 칸으로 돌아간다. 버리기는 우클릭 메뉴로만 한다.
- 내구도 바 색은 세 단계다: 50% 초과 초록(63c74d), 50% 이하 노랑(feae34), 25% 이하 빨강(e43b44). 모두 Endesga 32 팔레트 색이다 (Resurrect 64의 1ebc73·f9c22b·e83b3b에서 옮김).

## 창고 — 확정

- 거점에 창고가 있다. 창고 화면은 오른쪽에 뜨고, 인벤토리와 나란히 보인다.
- 창고는 100칸이고, 스크롤해서 아래 칸을 볼 수 있다.
- 인벤토리와 창고 사이에 끌어서 옮길 수 있다. 같은 화면 안에서 칸끼리 옮기는 것과 같은 규칙이다 (빈 칸이면 옮기기, 찬 칸이면 자리 바꾸기).
- 핫바에 올린 머리뼈를 창고로 옮기면 핫바 칸이 빈다.
- 창고는 거점의 상자 근처에서 F를 눌러 연다. 가까이 가면 안내가 뜬다. 지역에서는 창고를 열 수 없다.
- 창고를 열면 인벤토리도 같이 열린다.
- 우클릭 메뉴: 창고 칸에는 "인벤토리로 옮기기", 창고가 열려 있을 때 인벤토리 칸에는 "창고로 옮기기"가 추가된다. 받는 쪽이 가득 차면 회색으로 "가득 참"을 보여준다.
- 뼈는 창고에서도 한 칸에 개수 제한 없이 쌓인다. 끌어서 같은 종류의 뼈 칸에 놓으면 자리를 바꾸지 않고 합쳐진다. 인벤토리 안에서도 같다.
- 소환 중인 머리뼈는 창고로 옮길 수 없다. 끌어 놓으면 취소되고, 메뉴에서는 회색으로 "소환 중"을 보여준다.
- 창고는 Tab·Esc를 누르거나 상자에서 멀어지면 인벤토리와 함께 닫힌다.
- "옮기기" 메뉴로 보낸 물건은 받는 쪽에서 같은 종류의 뼈 칸에 합쳐지고, 없으면 가장 앞의 빈 칸에 들어간다.

## 지역 상자 — 확정

- 지역에 상자가 있다. 상자는 재료를 얻는 곳이다. 위험한 몬스터 근처에도, 건물이나 장소에도 있을 수 있다.
  - 시험 지역에는 임시로 두 곳: 멧돼지 근처 하나, 몬스터 없는 곳 하나.
- F로 연다. 창고처럼 인벤토리는 가운데 왼쪽, 상자는 오른쪽에 열린다. 가까이 가면 안내가 뜬다.
- 처음에는 안에 든 아이템이 무엇인지 모른다. 시간이 지나면 하나씩 무엇인지 드러난다.
  - 앞 칸부터 차례로, 한 번에 하나씩 드러난다.
  - 빈 칸도 드러나기 전에는 빈 칸인지 모른다.
  - 아직 드러나지 않은 칸은 "?" 칸이고, 드러나는 중인 칸에는 진행 바가 보인다.
- 확인 시간은 아이템의 희귀도에 따라 다르다. 희귀도는 4단계이고, 지금은 확인 시간에만 쓴다.
  - 확인 시간 (임시값): 1초 / 2.5초 / 5초 / 7.5초.
- 확인은 상자 창을 열어 둔 동안만 진행된다. 닫으면 멈춘다.
- 상자를 연 동안 상자 주변 일정 거리(48, 임시값) 안에서는 움직일 수 있다. 거리를 벗어나면 닫힌다.
- 닫았다 다시 열어도 이미 확인한 것은 그대로 남는다 (진행 중이던 칸도 멈춘 자리에서 이어진다).
- 맞아도 확인은 끊기지 않는다 (인벤토리·창고가 맞아도 닫히지 않는 것과 같다. 시체 채집은 맞으면 취소되는 것과는 다르다).
- 드러난 아이템을 보고 가져갈지 정한다. 가져가는 방법은 창고와 같다 (끌어서 옮기기, 우클릭 메뉴 "인벤토리로 옮기기").
  - 창고처럼 상자에 넣을 수도 있다. 드러나지 않은 칸에서는 꺼낼 수도, 그 칸에 넣을 수도 없다.
- 거점으로 돌아갔다가 다시 나오면 상자가 새로 채워진다 (지역에 들어올 때마다 새로 굴린다).
- 상자 칸 수는 상자마다 다르다. 시험용 상자는 6칸 (임시값).
- **제안** (구현에는 이렇게 넣었다, 확인 필요):
  - 희귀도 이름: 흔함(1초) / 고급(2.5초) / 희귀(5초) / 전설(7.5초). 7~8초 정도라고 하셔서 7.5초로 넣었다.
  - 지금 아이템의 임시 희귀도: 뼈는 흔함, 쥐 머리뼈는 고급, 멧돼지·박쥐·투석병 머리뼈는 희귀. 전설은 아직 없다.
  - 빈 칸은 흔함 시간(1초)이 걸린다.
  - 드러나지 않은 칸에 마우스를 올리면 정보 줄에 "무엇인지 아직 모름".
  - 상자를 여는 판정은 창고 상자와 같은 반지름(24)이고, 열린 뒤 유지 거리(48)는 따로다.
  - 메뉴 이름은 받는 쪽 이름을 넣는다 ("상자로 옮기기", "상자 가득 참").

## Shift+좌클릭 빠른 옮기기 — 확정

- 인벤토리와 상자, 또는 인벤토리와 창고가 같이 열려 있을 때, 아이템을 Shift+좌클릭하면 반대쪽으로 바로 옮겨진다.
- 받는 쪽에 같은 뼈 칸이 있으면 합쳐지고, 없으면 가장 앞의 빈 칸에 들어간다 ("옮기기" 메뉴와 같은 규칙).
- 받는 쪽이 가득 차면 옮겨지지 않고, 가득 찼다는 표시를 보여준다.
- 상자에서 아직 확인되지 않은 아이템은 옮길 수 없다.
- 인벤토리만 열려 있을 때 Shift+좌클릭은 아무것도 하지 않는다.
- 소환 중인 머리뼈, 핫바에 올린 머리뼈에 관한 기존 규칙은 그대로 적용한다 (소환 중인 머리뼈는 창고·상자로 못 옮김, 핫바에 올린 머리뼈를 옮기면 핫바 칸이 빈다).
- **제안** (구현에는 이렇게 넣었다, 확인 필요):
  - 가득 찼다는 표시는 "뼈가 부족함"과 같은 자리(핫바 위 안내 문구)에 메뉴와 같은 글자로 잠깐 띄운다: "창고 가득 참" / "상자 가득 참" / "인벤토리 가득 참".
  - 소환 중인 머리뼈를 Shift+좌클릭하면 같은 자리에 "소환 중"을 띄운다.

## 핫바 — 확정

- 핫바는 2칸이다. 화면 왼쪽 아래에서 조금 위에 항상 보인다. 마나 바는 핫바 바로 아래에 둔다.
- 핫바에는 머리뼈를 놓을 수 있다. 인벤토리 칸 위치를 바꾸는 것과 같은 방식으로, 인벤토리의 머리뼈를 끌어서 핫바 칸에 놓는다.
- 핫바는 바로가기다. 핫바에 놓아도 머리뼈는 인벤토리에서 사라지지 않고, 끌기 전에 있던 인벤토리 칸으로 돌아간다.
- 핫바는 인벤토리 칸 번호가 아니라 그 머리뼈 자체를 가리킨다. 인벤토리에서 칸을 옮겨도 핫바는 같은 머리뼈를 가리킨다.
- 가리키던 머리뼈가 인벤토리에서 사라지면(버리기 등) 그 핫바 칸은 빈다.
- 핫바 칸에서 우클릭하면 핫바에서만 빠진다. 머리뼈는 버려지지 않는다.
- 이미 차 있는 핫바 칸에 놓으면 새 머리뼈로 바뀐다.
- 같은 종류의 머리뼈(예: 쥐의 머리뼈 두 개)를 두 핫바 칸에 각각 둘 수 있다. 서로 다른 머리뼈를 가리키기 때문이다.
- 똑같은 머리뼈 하나가 두 핫바 칸에 동시에 들어가지는 않는다. 이미 다른 핫바 칸에 있는 머리뼈를 놓으면 새 칸으로 옮겨지고 원래 칸은 빈다.
- 핫바 칸끼리 끌어서 놓으면 두 칸의 자리가 바뀐다. 핫바 바깥에 놓으면 취소된다.
- 핫바 칸에도 머리뼈의 내구도 바를 보여준다.
- 핫바는 왼쪽부터 숫자키(1, 2)로 선택한다. 선택된 핫바 칸은 바깥쪽에 얇은 흰색 테두리가 생긴다.
- 소환 중인 머리뼈가 든 핫바 칸은 칸 안쪽 가장자리가 노란 테두리로 덮인다. 선택 테두리와 같이 보일 수 있다.

## 소환과 언데드 — 확정

- G를 누르면 선택된 핫바 칸의 머리뼈로 언데드를 소환하고, 다시 G를 누르면 소환을 해제한다.
- 여러 마리를 동시에 소환할 수 있다.
- 마나 규칙을 그대로 적용한다: 소환할 때 마나를 쓰고, 소환 중인 언데드마다 유지비가 초당 든다.
- 마나가 0이 되면 모든 언데드가 소환 해제된다.
- 언데드는 네크로맨서와 일정 거리 안에서 따라다니다가, 적을 만나면 공격한다.
- 처음 소환할 때 뼈를 쓴다. 처음 소환 비용(뼈 개수)은 몬스터 데이터의 값을 따른다.
- 몬스터는 네크로맨서와 언데드를 똑같이 적으로 보고, 가장 가까운 대상을 노린다.
- 언데드는 자체 체력이 있다. 이 체력은 머리뼈에 저장된다.
  - 해제된 머리뼈의 체력은 저절로 차지 않고, 뼈를 써서 직접 회복한다.
  - 필요한 뼈 = 처음 소환 비용 × (모자란 체력 / 최대 체력), 소수점은 올림.
  - 회복하지 않았으면 다친 체력 그대로 소환된다.
  - 인벤토리에서 마우스를 올렸을 때 정보 줄에 머리뼈의 체력과, 지금 회복하려면 필요한 뼈 개수를 같이 보여준다.
- 언데드가 피해를 받을 때마다 머리뼈 내구도가 1 내려간다.
- 언데드가 죽은 판정이 되면 사라지고, 머리뼈 내구도가 크게 닳는다. 닳는 양은 몬스터 데이터의 값을 따른다. 쥐는 3이다.
- 소환 중인 머리뼈를 인벤토리에서 버리면 죽은 판정이 된다.
- 언데드가 죽는 일격에는 피해 내구도(1)를 따로 깎지 않고, 죽은 판정의 값만 깎는다.
- 머리뼈 하나로는 언데드 한 마리만 소환한다. 여러 마리는 여러 머리뼈로 소환한다.
- 소환 중인 머리뼈를 핫바에서 빼면(우클릭, 다른 머리뼈로 바꿈) 일반 해제가 된다.
- 마나가 0이 되어 해제될 때는 일반 해제다 (죽은 판정이 아니다).
- 체력이 0인 머리뼈로는 소환할 수 없다. 0보다 크면 그 체력으로 소환된다.
- 처음 소환할 때 뼈가 모자라면 소환되지 않고 "뼈가 부족함" 안내가 뜬다.
- 체력 회복: 선택된 핫바 칸의 머리뼈를 R로 회복한다. 소환 중인 머리뼈는 회복할 수 없다.
  - 뼈가 모자라면 가진 뼈만큼 일부 회복한다 (뼈 하나당 최대 체력 / 처음 소환 비용).
- 뼈 제거 (2026-11-11): 인벤토리의 머리뼈 우클릭 메뉴에서 "뼈 제거"를 고르면 머리뼈에 들어 있던 뼈를 인벤토리로 돌려받는다. 뼈는 사라지거나 소모되지 않는다.
  - 돌려받는 뼈는 지금 체력만큼이다: 체력 / 뼈 하나당 체력, 소수점은 버린다. 다친 만큼은 돌아오지 않는다.
  - 뺀 뒤 머리뼈는 처음 소환 전 상태가 된다. 다시 쓰려면 처음 소환 비용(뼈)을 낸다. 내구도는 그대로다.
  - **제안** (구현에는 이렇게 넣었다, 확인 필요):
    - 소환 중인 머리뼈는 뺄 수 없다 (회색 "소환 중", 회복하기와 같은 규칙).
    - 돌려받을 뼈가 0이면(처음 소환 전, 체력 0, 뼈 하나에 못 미치는 체력) 회색 "뼈 없음".
    - 돌려받을 뼈를 넣을 자리가 없으면(뼈 칸이 없고 빈 칸도 없음) 회색 "인벤토리 가득 참". 뼈 칸이 있으면 그 칸에 합쳐진다.
    - 쓸 수 있을 때 메뉴 이름에 돌려받을 개수를 붙인다: "뼈 제거 (4개)".
    - 한 번에 전부 뺀다 (몇 개만 빼기는 없다).
- 언데드가 노리는 대상은 아래 "언데드 능력치와 타게팅"을 따른다. 네크로맨서에게서 너무 멀어지면 추격을 그만두고 돌아온다.

## 언데드 능력치와 타게팅 — 확정

- 언데드는 원래 몬스터보다 약하다. 기본 배율을 두고, 몬스터마다 필요하면 따로 조정할 수 있게 한다.
- 배율은 체력과 공격력에만 적용한다. 이동 속도와 행동의 타이밍(예고, 돌진 거리, 도는 반경 등)은 원래 몬스터와 같게 둔다. 공격 거리·공격 간격도 같다 (예외: 쥐 언데드의 공격 거리는 아래. 쥐 언데드의 물기 전 멈춤과 언데드 투석병의 던지기 전·후 멈춤은 0이다, 위 "고블린 투석병". 사용자 결정, 2026-11-13).
- 이 배율은 내구도가 가득 찼을 때의 값이다. 내구도에 따른 감소는 그 위에 따로 적용한다 (미정).
- 네임드 언데드는 일반 언데드보다 배율이 높다.
- 임시값: 일반 체력 85%, 공격력 85% (합치면 약 72%). 네임드는 각각 원래 몬스터의 120%.
  - 메모: 네임드 120%는 원래 몬스터보다 강하므로 "언데드는 원래 몬스터보다 약하다"의 예외가 된다.
- 따라갈 때는 적어도 네크로맨서가 걷는 속도로 따라간다 (몬스터 속도가 느려도 걷는 네크로맨서를 따라오게). 싸울 때는 원래 몬스터의 속도다.
- 따라갈 때(싸우지 않을 때)는 언데드끼리 64px 이상 떨어지려 한다. 돌진 한 번에 둘 다 맞지 않게 하려는 것이다 (돌진은 노린 자리를 40px 지나고 맞는 범위가 20px). 싸우러 갈 때와 싸울 때는 넣지 않는다 (2026-11-08).
  - **제안** (구현에는 이렇게 넣었다, 확인 필요): 네크로맨서 곁에서 멈추는 거리를 간격의 0.6배(약 38px)까지 넓혔다. 원래 멈추는 거리(28px)로는 두 마리가 정확히 반대편에 서야만 떨어질 수 있어서다. 비켜 서는 힘은 떨어진 거리에 따라 약해지되(제곱근), 아주 약하면(0.05 미만) 멈춘다.
- 언데드는 이유 없이 먼저 공격하지 않는다. 다음 계기가 생기면 그 몬스터를 대상으로 정하고 싸우러 간다.
  - 네크로맨서를 노리는 몬스터가 네크로맨서의 공격 반경(기본 공격 사거리, 지금 300) 안에 들어온다.
  - 네크로맨서가 몬스터에게 공격을 맞힌다.
  - 그 언데드를 노리는 몬스터가 그 언데드의 공격 반경 안에 들어온다 (반격).
- 언데드의 공격 반경은 행동 조각의 공격 거리다 (다가가기·던지기: 공격 거리, 돌진: 돌진을 시작하는 거리, 박쥐: 돌진을 시작하는 거리). 네크로맨서의 공격 반경과는 다르다.
- 대상이 언데드의 공격 반경에 한 번 들어오면 대상을 고정한다. 고정된 동안은 새 계기가 생겨도 대상을 바꾸지 않는다.
- 고정되기 전(대상에게 가는 중)에 새 계기가 생기면 가장 최근 계기의 몬스터로 바꾼다.
- 대상이 죽거나, 대상이 네크로맨서에게서 300(leash, 임시값. 네크로맨서의 공격 반경과 같게 둔다. 120 → 160 → 300, 2026-11-12 사거리와 함께 사용자 결정)보다 멀어지면 고정이 풀리고 돌아온다.
- 대상이 없어졌을 때(죽음·풀림) 이미 계기 조건에 맞는 몬스터가 있으면(네크로맨서를 노리며 공격 반경 안, 그 언데드를 노리며 언데드 공격 반경 안, 네크로맨서가 5초(임시값) 안에 맞힌 몬스터) 그중 언데드에게 가장 가까운 것을 바로 대상으로 정한다. 새로 들어오는 순간만 계기로 보면, 이미 안에 있는 몬스터에게 언데드가 가만히 있게 되기 때문이다.
- 같은 프레임에 계기가 여럿이면 그중 언데드에게 가장 가까운 몬스터를 고른다.
- 지금 들어 있는 언데드 중 쥐·멧돼지·박쥐는 기본 배율을 쓴다.
- 예외: 언데드 투석병의 공격력 배율은 0.5다 (체력은 기본 배율. 사용자 결정, 2026-11-13). 던지기 전·후 멈춤을 0으로 둔 뒤 언데드 1 vs 적 1에서 언데드가 40% 이겨서 낮췄다. 측정: 1 vs 1 승률 40% → 5%, 1 + 네크로맨서 vs 1과 2 vs 1은 100%·95% 이김, 교착 0% (`tests/balance/results/2026-11-13_goblin_undead_ratio.md`). 데이터의 `undead_damage_ratio_override`로 둔다.
- 예외: 쥐 언데드의 공격 거리는 24px다 (적 쥐는 16px 그대로, 사용자 결정 2026-11-08). 멧돼지 돌진에 맞는 범위(20px) 밖에서 싸우게 해서, 둘이 한 번에 맞지 않게 하려는 것이다. 측정: 함께 죽은 판 37/50 → 0/50. 데이터의 `undead_attack_range_override`로 둔다.

## 거점과 탈출 — 확정

- 거점이 있다. 거점은 몬스터가 없는 안전한 곳이다.
- 지역에서 거점으로 돌아가려면 탈출 지점에 3초 동안 있어야 한다.
- 탈출 지점 안에 있는 동안 화면 아래에 게이지가 찬다. 3초가 지나 게이지가 다 차면 거점으로 돌아간다.
- 게이지가 다 차기 전에 탈출 지점을 벗어나면 게이지가 처음으로 돌아간다.
- 지역에서 죽으면 인벤토리의 물건을 전부 잃고 거점에서 다시 시작한다. 창고에 있는 것은 잃지 않는다.
- 탈출 게이지가 차는 중에 피해를 받아도 게이지는 끊기지 않는다.
- 탈출 지점은 지역 씬에 직접 배치한다. 개수와 위치는 지역마다 정한다. 바닥에 원으로 표시한다.
- 거점에서 지역으로 나갈 때는 출구 지점에 서서 F를 누른다. 가까이 가면 안내가 뜬다.
- 탈출할 때 소환 중인 언데드는 일반 해제된다 (머리뼈의 체력·내구도는 그대로).
- 거점에서도 소환할 수 있다.
- 거점에서 지역으로 나갈 때도 소환 중인 언데드는 일반 해제된다.
- 게임은 거점에서 시작한다.
- 거점에 돌아오면 네크로맨서의 체력과 마나가 가득 찬다.
  - 메모: 지금 체력과 마나는 네크로맨서 노드가 가지고 있어서, 씬이 바뀌면 가득 찬 값으로 다시 시작한다. 나중에 지역끼리 바로 이동하는 길이 생기면 체력과 마나를 전역 상태(`GameState`)로 옮겨야 한다. 그래야 지역 사이를 옮겨 다닐 때 줄어든 값이 이어진다.
- 지역에 들어갈 때도 체력과 마나는 가득 찬 상태로 시작한다.

## 길찾기와 벽 — 확정

- 몬스터와 언데드는 벽을 돌아서 대상에게 간다. 벽이 가로막지 않을 때만 지금처럼 직선으로 간다.
  - 언데드가 네크로맨서를 따라갈 때도 같다. (몬스터는 포기해도 시작 자리로 돌아가지 않는다, 2026-11-13)
- 날아다니는 몬스터(박쥐, 언데드 박쥐)는 대상에게 다가갈 때만 벽을 돌아간다. 예고·돌진·물러나기·돌기는 지금처럼 곧게 움직이고, 벽에 닿으면 미끄러진다.
  - 의도된 특성: 좁은 길로 끌어들이면 박쥐의 돌진이 벽에 끊긴다 (돌진은 벽에 닿으면 빗나간 것으로 끝난다). 확인 (3마리 무리, 30초, 서 있기만): 2칸 통로에서는 돌진 21번 중 16번이 벽에 끊기고 받은 피해 7.5, 6×6 굴에서는 끊김 0번, 피해 40.5.
- 몬스터는 보이는 대상만 감지한다. 감지 범위 안이어도 벽이 가리면 감지하지 못한다.
- 한 번 노린 대상은 모퉁이 뒤로 숨거나 감지 범위를 벗어나도 길을 따라 쫓는다. 포기하는 조건은 위 "몬스터 타게팅"의 종별 추격 포기 조건을 따른다 (2026-11-13 바꿈. 임시값: 쥐·투석병·박쥐는 대상과 350px 또는 못 본 지 5초, 멧돼지는 추격 6초 또는 못 본 지 3초).
- 네크로맨서의 기본 공격 탄은 벽에 막힌다.
- 돌진(멧돼지)과 던지기(투석병)는 대상이 공격 거리 안이어도 벽이 가로막으면 시작하지 않고 돌아서 다가간다. 벽 너머로 돌진하거나 던지며 벽에 붙어 있지 않게 하려는 것이다. 박쥐의 돌진은 위 선택대로 그대로 둔다.
- 박쥐 무리가 대상을 보고 있는지는 무리원 하나라도 대상까지 벽이 가리지 않으면 보는 것으로 친다 (사용자 결정, 2026-11-14. 예전에는 거리로만 봤다).
- **제안** (구현에는 이렇게 넣었다, 확인 필요):
  - 감지는 몬스터 몸 가운데에서 대상까지 선을 그어 벽이 가리는지로 본다.
- 메모: 예전에는 시작 자리에서 150(곧은 거리)을 넘으면 포기해서, 꺾인 길을 돌아오던 멧돼지가 대상에 닿기 전에 포기했다. 그래서 보이지 않는 동안은 거리 대신 시간으로 바꿨다 (사용자 결정). 확인: 실제 멧돼지 데이터로 벽 너머 우회 7.2초 만에 돌아와 예고 (2026-11-14 다시 재니 7.4초) (`scenario_pathfinding.gd`). 2026-11-14부터 멧돼지는 못 본 지 3초면 포기해서 이 우회를 하지 못한다 (위 "몬스터 타게팅"). 시나리오의 우회 단계는 포기 시간을 늘린 데이터 복사본으로 길찾기만 확인한다.

## 지역과 퀘스트 — 확정

- 지역이 여러 개 있다.
- 퀘스트가 주요 미션이다. 퀘스트 유형:
  - 특정 몬스터 잡기
  - 특정 몬스터의 머리뼈 얻기
  - 특정 몬스터의 언데드를 소환·사용해서 특정 몬스터 잡기

## 미정 항목

구현 전에 사용자에게 물어볼 것.

### 기본 구조
- [ ] 게임 시작 시 첫 언데드 또는 첫 머리뼈를 어떻게 얻는지
- [ ] 네크로맨서 자신이 성장하는지 (레벨, 장비, 기본 공격 강화 등)

### 소환과 언데드
- [ ] 마나 외에 동시에 유지할 수 있는 언데드 수의 제한이 있는지, 있다면 늘어나는 방식

### 머리뼈 내구도
- [ ] 수리 비용 (지금은 거점 수리 기계에서 뼈 1개 = 내구도 1, 임시. 언데드 강화 아이템과 함께 정한다. 위 "수리 기계")
- [ ] 내구도에 따른 능력치 감소 방식: 비례해서 연속 감소 / 구간별 감소

### 네임드
- [ ] 네임드 언데드의 추가 능력 (사용자가 나중에 정할 예정)
- [ ] 네임드 머리뼈의 등장 확률, 이름 생성 방식 (고정 목록 / 무작위 조합)

### 재료와 등급
- [ ] 언데드 등급 체계를 둘지, 둔다면 몇 단계인지
- [ ] 몬스터 3등급의 "강한 언데드"가 무엇인지 (강한 종류의 언데드 / 여러 마리 / 네임드 등)

### 시체
- [ ] 빈 시체를 언제 지우는지 (오래 싸우면 쌓인다)
- [ ] 조합 재료의 종류와 조합법 (굵은 뼈 외)
- [ ] 조합은 어디서 하는지 (언제든 / 거점에서만)

### 지역 상자
- [ ] 상자의 내용물 (지금은 임시로 뼈와 머리뼈만 넣었다: 칸마다 빈 칸 30%, 뼈 2~4개 45%, 쥐 머리뼈 15%, 멧돼지·박쥐·투석병 머리뼈 합쳐 10%. 데이터에 임시로 표시함)

### 마나
- [ ] 기본 공격 업그레이드를 얻는 방식

### 지역과 진행
- [ ] 지역 해금 방식 (퀘스트 완료 / 특정 몬스터 처치 등)
- [ ] 퀘스트 보상

## 설계 검토 메모

설계를 정할 때 같이 고려할 위험 요소. 결정이 아니라 판단 재료다.

- **아끼느라 못 쓰는 문제**: 네임드 머리뼈처럼 드문 물건이 쓸수록 닳으면, 플레이어가 아껴두기만 하고 쓰지 않을 수 있다. 내구도가 줄어드는 조건과 수리 가능 여부를 정할 때 이 점을 같이 본다.
- **내구도와 능력치 감소의 가독성**: 내구도가 1씩 줄 때마다 능력치가 조금씩 줄면 플레이어가 변화를 체감하기 어렵다. 구간별 감소가 더 읽기 쉬울 수 있다.
- **초반 지루함**: 네크로맨서가 매우 약하므로, 첫 언데드를 얻기까지의 시간이 길면 초반이 지루해진다. 첫 몇 번의 처치와 첫 소환은 빨라야 한다.
- **네임드의 동기**: 능력치가 "조금 더 높은" 것만으로는 수집할 이유가 약하다. 추가 능력을 정할 때 이 부분을 채운다.
- **콘텐츠 양**: 머리뼈 종류 수 = 몬스터 종류 수 = 언데드 종류 수다. 몬스터 하나를 추가할 때 언데드 버전 에셋까지 같이 늘어나므로, 언데드는 원본 몬스터 에셋을 변형해서 재사용하는 방식을 검토한다 (`docs/art-direction.md`).

# 게임 설계

이 문서는 사용자가 정한 내용(**확정**)과 아직 정하지 않은 내용(**미정**)을 나눠 적는다. 미정 항목은 구현하기 전에 사용자에게 묻는다.

## 한 줄 요약

약한 네크로맨서가 약한 몬스터의 뼈로 언데드를 소환하고, 그 언데드로 더 강한 몬스터를 잡아 그 몬스터의 얼굴뼈를 얻으며 점점 강한 군단을 만드는 탑다운 게임.

## 핵심 루프 (확정 내용으로 구성)

1. 네크로맨서가 약한 기본 공격으로 하위 몬스터를 잡는다.
2. 몬스터가 뼈를 떨어뜨린다. 일정 확률로 얼굴뼈도 떨어뜨린다.
3. 얼굴뼈와 뼈(또는 뼈를 조합한 재료)로 그 몬스터의 언데드를 소환한다.
4. 언데드로 더 강한 몬스터를 잡고, 그 몬스터의 얼굴뼈를 얻는다.
5. 지역별 퀘스트를 수행한다.

## 시점 — 확정

- 2D 탑다운 (`docs/art-direction.md`)

## 네크로맨서 — 확정

- 공격 수단은 기본 공격 하나뿐이다.
- 기본 공격은 매우 약하다. 네크로맨서 혼자서는 강한 몬스터를 잡는 것이 거의 불가능하다.
- 하위 몬스터는 기본 공격으로 잡을 수 있다.

## 몬스터와 드랍 — 확정

- 하위 몬스터를 잡으면 뼈를 떨어뜨린다. 개수는 몬스터마다 설정된 값을 따른다.
- 얼굴뼈는 몬스터에게서 일정 확률로 얻거나 파밍으로 얻는다.

## 얼굴뼈 — 확정

- 얼굴뼈는 종류가 매우 다양하다. 각 얼굴뼈는 특정 몬스터의 언데드를 소환한다.
- 얼굴뼈에는 내구도가 있다. 내구도가 내려갈수록 그 얼굴뼈로 소환한 언데드의 능력치가 내려간다.
- 드물게 **이름이 있는 얼굴뼈**가 나온다.
  - 일반: "전사의 얼굴뼈" / 네임드: "전사 XXX의 얼굴뼈"
  - 네임드 얼굴뼈는 네임드 언데드를 소환한다.
  - 네임드 언데드는 일반 언데드보다 능력치가 조금 더 높다.

## 소환 재료 — 확정

- 강한 몬스터의 언데드일수록 필요한 재료가 많아진다.
- 고급 언데드는 일반 뼈를 더 많이 쓰거나, 뼈를 조합해 만든 재료(예: 굵은 뼈)를 요구한다.

## 지역과 퀘스트 — 확정

- 지역이 여러 개 있다.
- 퀘스트가 주요 미션이다. 퀘스트 유형:
  - 특정 몬스터 잡기
  - 특정 몬스터의 얼굴뼈 얻기
  - 특정 몬스터의 언데드를 소환·사용해서 특정 몬스터 잡기

## 미정 항목

구현 전에 사용자에게 물어볼 것.

### 기본 구조
- [ ] 익스트랙션 요소를 넣는지: 지역에 들어갔다가 탈출해야 전리품을 지키는지, 죽으면 무엇을 잃는지
- [ ] 게임 시작 시 첫 언데드 또는 첫 얼굴뼈를 어떻게 얻는지
- [ ] 네크로맨서 자신이 성장하는지 (레벨, 장비, 기본 공격 강화 등)

### 소환과 언데드
- [ ] 동시에 유지할 수 있는 언데드 수의 제한과 그 제한이 늘어나는 방식
- [ ] 언데드 조작 방식: 자동으로 따라다니며 싸움 / 명령을 내림 / 섞음
- [ ] 언데드가 쓰러지면 어떻게 되는지 (재소환 가능 여부, 얼굴뼈 내구도에 주는 영향)
- [ ] 같은 얼굴뼈로 여러 마리를 소환할 수 있는지

### 얼굴뼈 내구도
- [ ] 내구도가 줄어드는 조건: 소환할 때마다 / 소환 유지 시간 / 언데드가 피해를 받거나 쓰러질 때
- [ ] 내구도가 0이 되면: 얼굴뼈 파괴 / 소환 불가 / 최저 능력치로 유지
- [ ] 내구도를 수리할 수 있는지, 수리 재료는 무엇인지
- [ ] 내구도에 따른 능력치 감소 방식: 비례해서 연속 감소 / 구간별 감소

### 네임드
- [ ] 네임드 언데드의 추가 능력 (사용자가 나중에 정할 예정)
- [ ] 네임드 얼굴뼈의 등장 확률, 이름 생성 방식 (고정 목록 / 무작위 조합)

### 재료와 등급
- [ ] 언데드 등급 체계를 둘지, 둔다면 몇 단계인지
- [ ] 조합 재료의 종류와 조합법 (굵은 뼈 외)
- [ ] 조합은 어디서 하는지 (언제든 / 거점에서만)

### 지역과 진행
- [ ] 지역 해금 방식 (퀘스트 완료 / 특정 몬스터 처치 등)
- [ ] 퀘스트 보상
- [ ] 거점(은신처) 유무

## 설계 검토 메모

설계를 정할 때 같이 고려할 위험 요소. 결정이 아니라 판단 재료다.

- **아끼느라 못 쓰는 문제**: 네임드 얼굴뼈처럼 드문 물건이 쓸수록 닳으면, 플레이어가 아껴두기만 하고 쓰지 않을 수 있다. 내구도가 줄어드는 조건과 수리 가능 여부를 정할 때 이 점을 같이 본다.
- **내구도와 능력치 감소의 가독성**: 내구도가 1씩 줄 때마다 능력치가 조금씩 줄면 플레이어가 변화를 체감하기 어렵다. 구간별 감소가 더 읽기 쉬울 수 있다.
- **초반 지루함**: 네크로맨서가 매우 약하므로, 첫 언데드를 얻기까지의 시간이 길면 초반이 지루해진다. 첫 몇 번의 처치와 첫 소환은 빨라야 한다.
- **네임드의 동기**: 능력치가 "조금 더 높은" 것만으로는 수집할 이유가 약하다. 추가 능력을 정할 때 이 부분을 채운다.
- **콘텐츠 양**: 얼굴뼈 종류 수 = 몬스터 종류 수 = 언데드 종류 수다. 몬스터 하나를 추가할 때 언데드 버전 에셋까지 같이 늘어나므로, 언데드는 원본 몬스터 에셋을 변형해서 재사용하는 방식을 검토한다 (`docs/art-direction.md`).

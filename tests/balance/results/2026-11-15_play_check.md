# 봇 측정 3단계 3e: 직접 플레이로 봇 실력 단계 맞춰 보기 (2026-11-15)

계획: `docs/plans/2026-11-15_bot_measure_plan.md` 3단계 3e (사용자 결정 2026-11-15: 기준 숫자를 고르기 전에 직접 플레이 확인). 2단계 통과 기준의 "사용자가 보는 것"(직접 해 본 느낌과 봇 실력 단계가 맞는지)이다.

## 한 것

사용자가 `tools/play_case.gd`로 시험 지역의 측정과 같은 싸움을 혼자(언데드 없이) 해 봤다. 창은 메인 대화가 띄웠다.
- `bash tools/godot.sh --path . -s tools/play_case.gd -- --target=boar` (멧돼지 1마리)
- `… -- --target=goblin_pair` (고블린 투석병 둘)
- `… -- --target=bat_pack` (박쥐 무리(3))

세 창의 로그 모두 ERROR 줄 0 (`grep -c ERROR`: 멧돼지 0, 투석병 0, 박쥐 0. 로그 첫머리 "시험 상황: 멧돼지 1마리" · "고블린 투석병(2)" · "박쥐 무리(3), 쥐 머리뼈 0개").

## 사용자가 알려 준 결과 (사용자의 말 그대로)

| 대상 | 사용자 | 봇 (2단계 바꾼 뒤, 혼자 20판: 받은 피해 숙련·보통·초보 / 죽음 / 잡은 시간) |
|---|---|---|

| 박쥐 무리(3) | "박쥐는 좀 오래 걸리는거 빼곤 쉽게 깼어." (판 수·체력은 적지 않음) | 1.1·1.8·9.0 / 0·0·65% / 19.6·21.0·23.2초 |

## 정한 것 (선택 UI, 사용자 결정 2026-11-15)

- 직접 해 본 결과는 봇의 숙련과 비슷하다 (선택 UI "숙련과 비슷함". 메인 대화의 추천은 "숙련보다 잘함"이었다).
- 무리 기준을 고를 때 봇의 실력 줄은 숙련 = 적응한 사람, 보통 = 처음 하는 사람으로 본다. 초보 봇은 아주 서툰 사람의 참고로만 본다 (선택 UI "숙련=적응한 사람, 보통=처음 하는 사람").

## 참고

- 사람은 판을 거듭하며 나아졌다 (투석병: 처음엔 피해, 점점 쉬움). 봇은 판마다 같은 실력이다.
- 무리(멧돼지 무리·투석병 무리·섞인 무리·쥐 큰 무리)는 play_case가 아직 세우지 못해 직접 해 보지 않았다.
- 박쥐 무리는 "좀 오래 걸린다"는 느낌이 있었다 (봇 숙련 19.6초). 값 조정은 이 단계의 범위가 아니다.
- 쥐 패거리 기준(`docs/game-design.md` "몬스터 무리": 적응한 사람 = 숙련·보통 봇, 적응하지 못한 사람 = 초보 봇)은 이번 결정과 실력 줄을 보는 꼴이 다르다. 쥐 패거리 줄은 그대로 두고, 꼴이 다르다는 메모를 game-design.md "몬스터 무리"에 남겼다 (선택 UI "그대로 두고 꼴이 다르다는 메모만", 사용자 결정 2026-11-15).

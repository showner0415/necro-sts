# 측정 봇 피하기 변경 계획과 구르기 무적 제거 순서 (2026-11-10)

상태: **계획. 구현 전이다.** 쥐 언데드 멈춤 0을 적용한 값(`2026-11-10_rat_undead_no_windup.md`)을 "지금"으로 쓴다.

## 지금 방식의 문제

- 공격마다 실력별 확률(90 / 60 / 25%)로 피할지 정한다. 예고 시간, 돌 속도, 그림자 크기를 바꿔도 피하는 비율이 그대로다.
- 맞은 공격은 대부분 "피하려 하지 않음"에서 나온다. 굴렀을 때는 3~5%만 맞는다.

## 바꾸는 규칙

SKILLS에서 `dodge`(회피 성공률)를 빼고 `capacity`(동시 처리 수)를 넣는다. 실력 차이는 반응 시간, 조준 오차, 동시 처리 수로만 나눈다.

| 실력 | 반응 시간 | 조준 오차 | 동시 처리 수 (첫 값, 제안) |
|---|---|---|---|
| 숙련 | 0.18초 | 0도 | 3 |
| 보통 | 0.30초 | 3.5도 | 2 |
| 초보 | 0.45초 | 7도 | 1 |

`scan_interval`(둘러보는 간격)은 사용자가 정한 값이고 cone 시야에서만 쓰므로 그대로 둔다. 기본인 full 시야에는 영향이 없다.

공격마다 프레임마다 다음을 계산한다.

1. **닿기까지 남은 시간**
   - 멧돼지: 남은 예고 + (거리 − 맞는 범위 20) / 돌진 속도 280
   - 박쥐: 남은 예고 + (거리 − 물기 범위 13) / 돌진 속도 300
   - 돌: 남은 비행 거리 / 돌 속도 160
2. **벗어나야 할 거리**: 공격 줄(또는 그림자 원)까지의 여유를 뺀, 맞는 범위 밖까지의 거리
3. **판단**: (남은 시간 − 남은 반응 시간) 동안 그 거리를 갈 수 있으면 피한다. 수단은 걷기(쏘는 중 50, 아니면 80), 뛰기(130), 구르기(64px / 0.3초) 중 가장 가벼운 것을 고른다. 스태미나와 벽을 반영한다.
4. **못 갈 공격에는 피하기를 시도하지 않는다.** 표에는 "시간 부족"으로 센다.
5. **구르는 방향**: 지금은 첫 공격의 옆쪽만 본다. 16방향을 시험해서, 처리하는 공격 모두를 가장 많이 벗어나는 쪽을 고른다.

### 고칠 파일

- `tests/balance/player_bot.gd`: 위 규칙
- `monsters/behaviors/charge_behavior.gd`, `dive_behavior.gd`: 남은 예고 시간을 읽는 함수만 추가 (게임 동작은 바꾸지 않음)
- `tests/balance/run_diagnose.gd`: "피하려 하지 않음" 열을 "시간 부족" / "처리 수 초과"로 교체
- `CLAUDE.md`의 봇 설명

## 사용자 결정 (2026-11-10)

1. 반응 시간은 **피할 수 있게 된 때**부터 잰다. 멧돼지는 방향이 고정된 순간, 박쥐는 예고 시작, 돌은 던진 순간이다. 박쥐는 날아오기 시작한 뒤 0.12~0.21초면 닿으므로 구르기를 돌진 시작에 겹치도록 예고부터 잰다.
2. 반응 시간은 **고정값**이다 (공격마다 흔들지 않는다). 수치를 조금 바꿀 때 결과가 0%와 100% 사이로 튈 수 있다는 점을 알고 정했다. 결과가 그렇게 튀면 보고한다.
3. 동시 처리 수를 넘는 공격은 **안 본 것으로** 친다. 가장 급한 공격 N개만 보고 구를 방향을 정하며, 나머지는 위치에 따라 맞거나 피해진다. 주사위는 없다.
4. 무적을 0으로 재는 단계에서 설계 문서의 확정 규칙도 **바로 바꾼다** (0.2초 값은 기록으로 남긴다). 봇 변경과 새 기준 측정이 끝나기 전에는 바꾸지 않는다.

동시 처리 수 3 / 2 / 1은 첫 값이다 (제안).

## 기준표 예상

임시로 봇을 고쳐서 상한을 쟀다. 모든 공격을 피하려고 시도하게 한 값이다 (반응 시간은 지금 그대로, 구르기 무적 0.2초 그대로, 50판). 코드는 측정 뒤 되돌렸다.

| 죽음 | 숙련: 지금 → 상한 | 보통: 지금 → 상한 | 초보: 지금 → 상한 |
|---|---|---|---|
| 멧돼지 혼자 | 2 → 0% | 78 → 0% | 100 → 0% |
| 멧돼지 + 쥐 언데드 2 | 0 → 0% | 2 → 0% | 48 → 0% |
| 박쥐 무리 혼자 | 0 → 0% | 4 → 0% | 78 → 0% |
| 박쥐 무리 + 쥐 언데드 2 | 0 → 0% | 2 → 0% | 50 → 0% |
| 고블린 2 혼자 | 0 → 0% | 16 → 0% | 90 → 2% |
| 고블린 2 + 쥐 언데드 2 | 0 → 0% | 2 → 0% | 62 → 0% |

| 받은 피해 평균 | 숙련: 지금 → 상한 | 보통: 지금 → 상한 | 초보: 지금 → 상한 |
|---|---|---|---|
| 멧돼지 혼자 | 4.0 → 0.0 | 9.1 → 0.0 | 10.0 → 0.0 |
| 박쥐 무리 혼자 | 1.7 → 1.5 | 4.3 → 1.5 | 9.5 → 1.8 |
| 고블린 2 혼자 | 1.6 → 0.2 | 5.8 → 0.3 | 9.8 → 1.1 |

| 잡은 시간 | 숙련 | 보통 | 초보 |
|---|---|---|---|
| 멧돼지 혼자 (상한) | 30.3초 | 31.2초 | 41.8초 |
| 박쥐 무리 혼자 (상한) | 26.2초 | 30.3초 | 36.6초 |
| 고블린 2 혼자 (상한) | 13.5초 | 16.0초 | 23.9초 |

멧돼지의 반응 시간을 방향이 고정된 순간부터 재도 결과가 같았다 (받은 피해 0.0, 죽음 0%, 모든 실력).

### 예상

- **죽음은 모든 실력에서 거의 0%가 된다.** 새 방식은 위 상한에 가깝게 나올 것이다. 구르기 무적이 늦은 구르기까지 살려 주기 때문이다. 판단 3의 "갈 수 있는가"가 실제로 걸러 내는 공격이 적다.
- 실력 차이는 잡은 시간과 약간의 피해로만 남는다. 지금처럼 초보 78~100% 사망 같은 차이는 사라진다.
- 동시 처리 수도 무적이 있는 동안은 효과가 작다. 예고 끝에 구르면 0.2초 무적이 박쥐 돌진을 통째로 덮는다 (닿기까지 0.12~0.21초).
- 쥐 줄은 바뀌지 않는다. 쥐는 예고가 없어 피하기 규칙을 타지 않는다. 쥐 기준(보통 8.2초, 초보 13.6초 이내)은 그대로다.
- 언데드 대결의 "언데드 1 + 네크로맨서"만 봇을 쓰므로 바뀐다. 멧돼지 경우의 네크로맨서 사망 28%는 크게 줄 것이다. 다른 대결은 봇이 싸우지 않아 그대로다.

실력 차이는 구르기 무적을 0으로 바꾼 다음 단계에서 다시 벌어질 것으로 본다. 그때 값은 예측하지 않고 재서 적는다. 지금의 기준표는 새 봇과 비교할 수 없으므로, 새 봇으로 기준을 다시 만든다.

## 구르기 무적 제거 (6번) 순서

1. 봇 변경을 끝내고 새 기준을 잰다 (무적 0.2초).
2. `necromancer.tscn`에서 `roll_invincible_duration`을 0으로 두고 같은 조건으로 잰다. 코드는 그대로이고 값만 바꾸므로 되돌릴 수 있다.
3. 두 표를 따로 보고한다.

### 설계 문서의 확정 규칙

바꾸기 전에 알린다. `docs/game-design.md`에 다음이 확정으로 적혀 있다.

- 뛰기·구르기 — 확정: "구르기 시간의 앞부분 일부만 무적이다."
- 멧돼지: "구르기 무적 중에 돌진에 닿으면 피해는 없고 밀려나기만 한다."
- 박쥐: "걷기로는 피하지 못하고, 날아오는 순간 구르면 무적으로 피한다." "제때 구르면 피할 수 있어야 한다."

`scenario_boar.gd`의 "구르기 무적 중에는 밀려나기만"과 `scenario_stamina.gd`의 "앞부분 무적" 단계는 무적을 0으로 하면 실패한다. 이 두 시나리오는 테스트 안에서만 무적을 0.2초로 켜서, 기능이 계속 동작하는지 확인하게 고친다.

### 피할 수 없는 공격 시나리오 (새 `scenario_roll_no_iframe.gd`, 무적 0)

프레임을 정확히 맞추는 입력으로 "빠져나갈 길이 있는가"를 본다. 시작 거리와 각도를 여러 개 돌려 성공한 경우와 여유(픽셀)를 출력한다. 아래 계산은 코드의 수치로 낸 예상이고, 시나리오로 확인해야 한다.

| 경우 | 계산 | 예상 |
|---|---|---|
| a. 2칸(64px) 길목, 멧돼지 정면 돌진 | 몸 가운데는 길목 가운데에서 ±26까지 간다. 돌진 맞는 범위는 20이라 옆으로 비키면 여유 약 6px. 뒤로 구르면 노린 자리 +64로, 돌진 끝(+40)과 맞는 범위(20)를 합친 +60보다 약 4px 더 간다 | 빠듯하게 가능. 벽 다듬기·멧돼지 위치에 따라 불가능할 수 있다 |
| b. 박쥐 셋 동시 돌진 | 120도 간격이면 가장 좋은 방향에서도 두 줄과는 30도라 구르는 동안 옆으로 초당 약 107px. 물기 범위 13을 벗어나는 데 0.12초. 닿기까지 0.12~0.21초 | 도는 거리 50 근처 박쥐는 빠듯함. 돌진 시작에 구르기를 겹쳐야 한다 |
| c. 돌 그림자 원 | 가운데에서 12px 벗어나는 데 구르기 0.06초, 걷기 0.15초. 던지는 거리 90~140에서 돌이 닿기까지 0.56~0.88초. 던지기 전 멈춤 0.3초 동안은 그림자가 아직 없다 | 여유 있게 가능 |

피할 수 없는 경우가 나오면 무적 되살리기와 몬스터 쪽 변경(예: 좁은 곳에서 멧돼지가 돌진하지 않음)을 선택지로 묻는다.

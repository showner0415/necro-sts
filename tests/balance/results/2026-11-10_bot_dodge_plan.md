# 측정 봇 피하기 변경 계획 2판 (2026-11-10)

**보류: 3D 전환 후 재개**

## 재개할 때 할 일

- 반응 시간에 실력별 흔들림(예: ±0.05초) 추가 검토 (예고 시험의 절벽 문제: 멧돼지 혼자·보통 실력의 죽음이 고정 시간 +0.2초에 74% → 0%로 뛴다)
- 초보 반응 시간 0.38초 안 (지금 0.45초면 박쥐 혼자 돌진을 어느 반경에서도 못 피한다)
- 멧돼지는 "좁은 곳 돌진 금지" 대신 "좁은 곳에서는 방향 고정을 길게" 쪽으로 본다
- a·b·c 시나리오를 실제로 실행하고, 구르기 무적 0을 무적 0.2초 기준과 따로 비교한다

아래는 보류 전의 계획이다. "지금"은 쥐 언데드 멈춤 0을 적용한 값(`2026-11-10_rat_undead_no_windup.md`)이다.

## 왜 고치나

1판(갈 수 있으면 반드시 피함)은 임시 측정에서 죽음이 모든 실력에서 거의 0%였다. 실력 차이와 예고의 효과를 잴 수 없다.

## 규칙

공격마다 한 번 판단한다.

1. **여유** = (닿기까지 남은 시간 − 반응 시간) − 피하는 데 필요한 시간
   - 닿기까지 남은 시간과 반응 시간을 재기 시작하는 때:

   | 공격 | 재기 시작 | 닿기까지 남은 시간 |
   |---|---|---|
   | 멧돼지 | 방향이 고정된 순간 | 고정 시간 + (거리 − 20) / 280 |
   | 박쥐 | 예고 시작 | 예고 시간 + (거리 − 13) / 300 |
   | 돌 | 던진 순간 | 남은 비행 거리 / 160 |

   - 필요한 시간 = 맞는 범위 밖까지의 거리 / 수단의 속도. 걷기 여유가 0.1초 이상이면 걷고, 아니면 구른다 (스태미나·벽 반영).
2. **여유가 0 이하면 피하지 않는다** ("시간 부족"으로 센다).
3. **여유가 있으면 실패 확률을 굴린다.** 실패하면 그 공격에는 입력을 하지 않는다 (늦게 구르게 하면 무적이 있는 동안 살아나서 측정에 안 드러난다).
4. **방향 실수**: 피하기로 했을 때 실력별 확률로, 16방향 중 평가가 나쁜 절반에서 무작위로 고른다.
5. **동시 처리 수**: 0.25초 안에 닿는 공격 중 가장 급한 N개만 보고 방향을 정한다. 나머지는 안 본 것으로 친다.

반응 시간은 사용자 결정대로 고정값이다.

## 값 (제안)

실패 확률 = 바닥 + (1 − 바닥) × exp(−여유 / 기울기)

| 실력 | 반응 시간 | 조준 오차 | 동시 처리 | 기울기 | 바닥 | 방향 실수 |
|---|---|---|---|---|---|---|
| 숙련 | 0.18초 | 0도 | 3 | 0.05 | 2% | 3% |
| 보통 | 0.30초 | 3.5도 | 2 | 0.09 | 5% | 10% |
| 초보 | 0.45초 | 7도 | 1 | 0.18 | 12% | 25% |

| 여유 | 0.05초 | 0.1초 | 0.2초 | 0.3초 | 0.5초 |
|---|---|---|---|---|---|
| 숙련 실패 | 38% | 15% | 4% | 2% | 2% |
| 보통 실패 | 60% | 36% | 15% | 8% | 5% |
| 초보 실패 | 79% | 62% | 41% | 29% | 17% |

지금 수치에서 나오는 여유 (초):

| 상황 | 숙련 | 보통 | 초보 |
|---|---|---|---|
| 멧돼지, 거리 64 / 100 / 140 | 0.08 / 0.21 / 0.36 | 시간 부족 / 0.09 / 0.24 | 시간 부족 / 시간 부족 / 0.09 |
| 박쥐 동시 돌진, 반경 50 / 75 | 0.22 / 0.31 | 0.10 / 0.19 | 시간 부족 / 0.04 |
| 박쥐 혼자 돌진, 반경 50 / 75 | 0.12 / 0.21 | 0.00 / 0.09 | 시간 부족 / 시간 부족 |
| 돌(걷기), 거리 100 / 140 | 0.22 / 0.47 | 0.10 / 0.35 | 시간 부족 / 0.20 |

## 임시 측정

실패 확률만 임시로 봇에 넣어 쟀다. 방향 실수, 동시 처리 수, 16방향 고르기는 넣지 않았다. 구르기 무적 0.2초 그대로, 50판. 코드는 측정 뒤 되돌렸다.

| 죽음 | 숙련: 지금 → 임시 | 보통: 지금 → 임시 | 초보: 지금 → 임시 |
|---|---|---|---|
| 멧돼지 혼자 | 2 → 0% | 78 → 74% | 100 → 100% |
| 멧돼지 + 쥐 언데드 2 | 0 → 0% | 2 → 4% | 48 → 62% |
| 박쥐 무리 혼자 | 0 → 0% | 4 → 0% | 78 → 98% |
| 박쥐 무리 + 쥐 언데드 2 | 0 → 0% | 2 → 0% | 50 → 82% |
| 고블린 2 혼자 | 0 → 0% | 16 → 0% | 90 → 50% |
| 고블린 2 + 쥐 언데드 2 | 0 → 0% | 2 → 0% | 62 → 40% |

| 받은 피해 평균 | 숙련: 지금 → 임시 | 보통: 지금 → 임시 | 초보: 지금 → 임시 |
|---|---|---|---|
| 멧돼지 혼자 | 4.0 → 1.0 | 9.1 → 9.3 | 10.0 → 10.0 |
| 박쥐 무리 혼자 | 1.7 → 1.7 | 4.3 → 3.2 | 9.5 → 10.0 |
| 고블린 2 혼자 | 1.6 → 0.4 | 5.8 → 1.3 | 9.8 → 8.3 |

해석:
- 실력 차이가 다시 나타난다.
- 박쥐 초보가 78%에서 98%로 나빠졌다. 혼자 돌진의 여유가 어느 반경에서나 시간 부족이라 한 번도 피하지 않기 때문이다. 곡선이 아니라 반응 시간 0.45초가 예고 0.3초보다 긴 탓이다. 초보 반응 시간을 줄이면(예: 0.38초) 혼자 돌진은 반경 75에서 조금 피하게 된다.
- 쥐는 예고가 없어 바뀌지 않는다.
- 방향 실수와 동시 처리 수는 무적이 있는 동안 효과가 작을 것이다. 무적이 돌진을 덮기 때문이다. 무적 0 뒤에는 크게 작용한다 (아래 박쥐 계산).

## 예고 시간 시험

멧돼지 예고에는 두 가지 늘리기가 있고 효과가 다르다. 반응 시간을 방향 고정부터 재므로, 고정 전 시간만 늘리면 봇의 여유가 변하지 않는다.

| 멧돼지 죽음 (임시 측정, 50판) | 숙련 | 보통 | 초보 |
|---|---|---|---|
| 혼자, 지금 (예고 0.7, 고정 0.2) | 0% | 74% | 100% |
| 혼자, 예고만 +0.2 (0.9 / 0.2) | 0% | 74% | 100% |
| 혼자, 고정 시간까지 +0.2 (0.9 / 0.4) | 0% | **0%** | 100% |
| 언데드 2, 지금 | 0% | 4% | 62% |
| 언데드 2, 예고만 +0.2 | 0% | 0% | 48% |
| 언데드 2, 고정 시간까지 +0.2 | 0% | 0% | 14% |

새 파일 `tests/balance/run_telegraph_check.gd` (데이터 복사로 값만 바꾼다, `run_all.sh`에는 넣지 않는다):
- 멧돼지 혼자·보통 실력·100판을 기본과 "고정 시간까지 +0.2초"로 잰다. 비교용으로 "예고만 +0.2초"도 출력한다.
- 죽음이 줄고 95% 범위가 겹치지 않으면 `[통과]`, 아니면 `[실패]`로 종료 코드 1이다.
- 혼자·보통이 74% → 0%로 크게 뛰는 것은 반응 시간이 고정값이라 생기는 절벽이다. 판단을 할 때 이 점을 같이 본다.

## 박쥐의 예고와 계산

박쥐에게는 돌진 전 예고가 있다. 멈춰서 깜빡이고, 혼자 돌진 0.3초, 동시 돌진 0.4초다. 방향 선은 없다. 방향은 돌진을 시작하는 순간 대상이 있던 쪽으로 정해진다 (`pack_lock_time` 0).

- 예고가 알려 주는 것은 **언제**이지 **어디로**가 아니다. 돌진이 시작된 뒤 닿기까지는 반경 50~75에서 0.12~0.21초라, 시작을 보고 반응하면 숙련(0.18초)도 늦다. 예고 덕분에 미리 눌러 구르기를 돌진 시작에 겹칠 수 있다.
- 예고를 늘려도 구르기로 벗어날 수 있는 거리는 늘지 않는다. 돌진 전에 움직여도 방향이 그쪽으로 다시 정해지기 때문이다. 벗어날 시간을 늘리는 것은 돌진 시작 반경이나 돌진 속도다.

1판의 계산은 틀렸다. 옆으로 벗어나는 속도만 봤고, 박쥐 쪽으로 구르면 더 빨리 닿는 것을 빼먹었다. 프레임 단위로 다시 계산했다 (무적 없음, 120도 간격, 입력 시각을 돌진 시작 기준으로 앞뒤로 옮겨 가며):

| 도는 반경 | 가장 좋은 방향에서 누를 수 있는 시간 폭 | 돌진 시작에 맞춰 누를 때 살아남는 방향 |
|---|---|---|
| 셋 다 50 | 0.15~0.22초 | 12/72 (17%) |
| 셋 다 62 | 0.20~0.27초 | 24~30/72 (33~42%) |
| 셋 다 75 | 0.23~0.35초 | 30~36/72 (42~50%) |
| 50 / 62 / 75 | 0.23~0.32초 | 22~26/72 (31~36%) |

폭의 범위는 구른 뒤 멈출 때 / 같은 방향으로 계속 걸을 때다. 틈은 있지만 방향을 맞혀야 한다. 어림으로 맞는 방향이 17~50%뿐이다. 실제 대형은 간격이 흐트러지므로 시나리오로 확인한다.

## a·b·c 시나리오 (무적 0)

프레임을 맞춘 입력으로 시작 거리·각도를 여러 개 돌려 "빠져나갈 길이 있는 비율"과 여유를 출력한다. 계산은 다음과 같다.

| 경우 | 계산 |
|---|---|
| a. 2칸 길목, 멧돼지 정면 돌진 | 길목 가운데에 있으면 옆으로 약 6px, 뒤로 구르면 약 4px 여유 |
| b. 박쥐 셋 동시 돌진 | 위 표 |
| c. 돌 그림자 원 | 구르기 0.06초·걷기 0.15초로 벗어남, 돌이 닿기까지 0.56~0.88초 |

피할 수 없거나 운에 가까우면 사용자가 정한 안을 선택지에 넣는다.
- 멧돼지: 폭 3칸 미만에서는 돌진하지 않음 / 좁은 곳에서는 예고를 길게
- 박쥐: 동시 돌진을 0.15~0.25초씩 어긋나게 / 한 번에 최대 두 마리만 돌진
- 멧돼지의 "돌진하지 않음"은 2칸 길목에 낀 멧돼지가 공격 없이 길만 막던 문제(2026-11-08)를 되살릴 수 있다. 지금의 물러나기 동작과 함께 측정해서 비교한다.

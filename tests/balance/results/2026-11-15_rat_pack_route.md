# 얕은 굴 초반 길에서 쥐 패거리 (2026-11-15, 계획 8b-6)

사용자 결정: 얕은 굴 초반 길(거점 → 입구 굴 → 쥐 둥지)로 확인한다. 몬스터는 입구 굴만 남긴다 (나머지 굴의 몬스터는 치움). 지나가는 길에서 싸움이 없어 쥐 패거리를 잡으러 가는 길도 더한다.

명령: `bash tools/godot.sh --headless --fixed-fps 60 --path . -s tests/balance/run_map_route.gd -- --routes=rat_gang,rat_gang_hunt` (실력 셋 × 언데드 0/2 × 5판, 끝까지 싸움). `SCRIPT ERROR`·`ERROR:` 0줄, `[실패] 판 시작 검사` 0줄, 마지막 줄 `결과: 통과`.

- 지나가기(rat_gang): 거점 → 입구 굴 가운데 → 쥐 둥지 가운데.
- 잡으러(rat_gang_hunt): 거점 → 입구 굴의 쥐에게 가까운 것부터 (멧돼지 잡으러 길과 같은 방식).
- 무리 크기와 대장은 판마다 던전 시드로 정해진다: 길마다 30판 중 3마리 16판, 4마리 14판, 대장이 있던 판은 지나가기 2판, 잡으러 3판.

## 요약

- 지나가기: 모든 판에서 싸움이 없다 (쏜 탄 0, 잡은 쥐 0, 피해 0). 입구 굴 가운데는 쥐 패거리 자리 (80, 122)에서 10칸(320px)이고 쥐 감지 범위는 80px라, 굴 가운데로 지나가면 쥐가 알아채지 못한다.
- 잡으러, 혼자: 죽음 0%. 받은 피해 평균 1.4 / 1.2 / 1.4, 가장 많이 5.0 / 5.0 / 6.0 (숙련 / 보통 / 초보, 체력 10). 시험 지역·벽 방(피해 0)과 달리 실제 굴에서는 물린다. 걸린 시간 51.3~54.7초는 거점에서 걸어간 시간이 들어 있어 싸움 시간과 바로 견줄 수 없다.
- 잡으러, 쥐 언데드 2: 피해 0. 언데드 죽음 판당 0.4 / 0.2 / 1.2 (쥐 패거리(4): 시험 지역 열린 바닥(8b-2) 1.9 / 2.0 / 1.9, 벽 방(8b-5) 1.6 / 1.8 / 2.0).
- 판 수가 5판이라 오차가 크다.
- 줄(실력·언데드 조건)마다 무리 구성이 다르다: 던전 난수는 첫 판에 한 번 시작되고 판 사이에 이어져(드랍도 같은 난수를 씀), 판 번호로 무리 크기·대장이 정해지지 않는다. 그래서 숙련·보통·초보 비교에는 무리 크기·대장 차이가 섞여 있다 (잡으러 길의 잡은 수가 줄마다 3.2~3.6).
